# AUTOCHESS v0.15.10 — Codex 통합 수정 지시서

> **기준 버전:** v0.15.9  
> **상태:** 사용자 요청 정리 / 구현 전  
> **범위:** 기존에 보류한 도감 개편 1건 + 이번 신규 요청 8건  
> **원칙:** v0.15.9까지 구현 완료된 사항은 다시 작업하지 않는다. 기존 전투·경제·아이템·저장 규칙은 아래에서 명시한 변경점 외에는 유지한다.

## 1. 조합의 ‘전체보기’ 삭제 및 도감 메뉴 개편 (이전 요청)

- 왼쪽 **조합** 패널의 **‘전체보기’ 버튼**을 삭제한다.
- 기존 조합 활성화 표시와 조합 계산은 유지한다.
- **도감** 메뉴에 아래 4개 진입 버튼을 제공한다.
  1. 캐릭터 도감
  2. 유대 도감
  3. 증강 도감
  4. 아이템 도감
- 각 버튼을 누르면 해당 전용 도감을 열 수 있게 한다.
- 기존 데이터·해금 상태·세부 정보 표시 및 게임 규칙을 보존한다. 현재 도감 화면 구조를 확인해 기존 기능을 잃지 않도록 재배치한다.

## 2. 동료 영입창: 구매 시 성급 상승 예고

- 동료 영입창의 각 후보에 대해 **지금 이 캐릭터를 구매하면 합성 결과가 2성 또는 3성이 되는 경우** 이를 미리 보여준다.
- 해당 후보 **캐릭터 이미지 위에 별 표시**를 배치한다. 실제로 구매 후 도달하는 성급(★★ 또는 ★★★)을 명확히 표시한다.
- 기존 보유 중 배지/청록 내부선 및 추천 금색 강조와 겹치지 않도록 배치한다.
- 계산은 **전장+대기석 보유 수량 및 현재 성급**, 기존 3개 자동 합성·연쇄 합성 규칙을 기준으로 한다. 구매 직후 실제로 발생하는 결과를 예고해야 한다.
- 구매, 판매, 합성, 배치/회수, 영입 후보 변경 후 즉시 갱신한다.
- 성급 상승이 발생하지 않는 후보는 별도 승급 예고를 표시하지 않는다. 기존 캐릭터 카드의 일반 성급 표시는 유지한다.
- **별 표시는 정보 안내일 뿐** 구매 비용, 합성 조건, 합성 로직을 변경하지 않는다.

## 3. 전투 승리 시 플레이어 체력 +2 회복

- **전투 승리 시 플레이어 체력을 2 회복**한다.
- 플레이어 체력 최대치는 **100**이며 초과 회복하지 않는다: `newHP = min(100, currentHP + 2)`.
- 패배 시 체력 감소 규칙과 v0.15.9의 하트 흔들림/숫자 감소 연출은 유지한다.
- 보급·증강 등 실제 전투가 아닌 단계에서 승리 보상을 잘못 지급하지 않는다.
- 기존 골드/이자/아이템 보상과 독립적으로 처리하며 이를 변경하지 않는다.
- 보스전 승리에도 동일하게 적용할지는 현재 전투 승리 판정 구조를 확인해 **일반 승리와 보스 승리를 모두 포함하는 기본안**으로 구현하되, 예외가 필요하면 보고한다.

## 4. 모든 보급 스테이지: 확률형 추가 골드 2~3G

- **모든 보급 스테이지**에 확률적으로 **추가 골드 2G 또는 3G**를 얻는 보상을 도입한다.
- 기존 보급 아이템 선택, 보급 진행, 라운드 전환 및 기존 골드 보상 규칙을 보존한다.
- 골드 지급 여부 및 2G/3G 선택은 중복 지급되지 않도록 스테이지당 1회 처리하고, 실제 지급 결과를 UI에 명확히 표시한다.
- **미확정 사항:** 발동 확률 및 발동 시 2G/3G 분포가 지정되지 않았다. Codex는 임의의 확률을 확정하지 말고 사용자에게 제안값을 제시해 승인을 받은 뒤 적용한다.

## 5. 라운드 전환 중앙 연출

- 라운드가 넘어갈 때 화면 중앙에 **`? ROUND` 형식의 큰 안내**를 잠시 표시한다. `?`에는 새 라운드 번호를 넣는다(예: `3 ROUND`).
- 짧은 등장 → 강조 → 퇴장 애니메이션을 사용한다.
- 기존 라운드 전환 및 보급/증강/전투 모달 처리와 충돌하지 않도록 한다.
- 애니메이션은 표시 연출이며 게임 로직을 중복 실행하거나 진행 상태를 변경하지 않는다.
- 배속, 장면 전환, 새 게임/종료, 모션 감소 설정을 고려한다. 구체적 지속 시간은 UI 테스트 후 조정 가능하다.

## 6. 동료 영입창: 1회성 상점 잠금

- 동료 영입창에 **잠금 토글 버튼**을 추가한다.
- 잠금을 켜면 **다음 라운드로 넘어갈 때 현재 영입 후보 5명이 그대로 유지**된다.
- **다음 라운드로 넘어가는 순간 잠금 상태는 자동 해제**된다. 즉, 현재 잠금은 한 번의 라운드 전환에만 적용된다.
- 잠금으로 유지된 후보는 다음 라운드에 그대로 보이되, 그 이후 라운드 전환에서는 사용자가 다시 잠그지 않았다면 정상 갱신된다.
- 잠금 여부를 버튼 모양/텍스트로 명확히 표시한다.
- 영입 후보의 구매·매진·수동 새로고침과 잠금의 상호작용은 기존 상점 로직을 확인해 처리한다. **명시되지 않은 정책을 임의로 확정하지 말고** 예상 동작과 예외를 구현 전에 보고한다.
- 저장/불러오기 및 장면 전환 시 잠금 상태와 후보 목록이 꼬이지 않도록 검증한다.

## 7. 캐릭터 정보창: 장착 아이템 툴팁 가림 해결

- 캐릭터 정보창에서 장착 아이템에 마우스를 올렸을 때 표시되는 **아이템 상세 툴팁이 캐릭터 정보창 뒤에 가려지는 문제**를 수정한다.
- 툴팁의 레이어(z-index), 포털 렌더링, 상위 요소의 `overflow`/클리핑, 위치 계산을 점검한다.
- 툴팁은 캐릭터 정보창보다 위에 표시하고 화면 밖으로 잘리지 않도록 한다.
- 기존 아이템 정보 내용 및 장착/해제 기능은 변경하지 않는다.

## 8. 6라운드 종료 시 게임 완료·계속 진행 확인 팝업

- **6라운드가 끝나면** 이번 게임의 기본 진행 구간이 종료되었음을 알리는 팝업을 표시한다.
- 팝업에 **‘게임 종료’와 ‘계속 진행’** 선택지를 제공한다.
- ‘계속 진행’을 선택하면 기존 게임 상태를 유지하고 다음 라운드로 진행한다.
- ‘게임 종료’를 선택하면 기존 게임 종료/결산 흐름에 맞게 처리한다. 현재 구현된 종료 처리 방식을 확인해 데이터 손실이나 중복 보상이 없게 한다.
- 6라운드 종료 판정이 **6라운드의 최종 전투/보스전 결과 및 보상 처리 후** 정확히 한 번만 발생하도록 한다.
- 팝업이 열린 동안 뒤에서 다음 라운드가 중복 시작되지 않게 한다.
- 사용자가 계속 진행한 뒤 7라운드 이후 동작, 재접속 시 팝업 복원, 패배/게임오버와 충돌하는 경우를 테스트한다.

## 9. 아이템 패널 좌우 여백 추가 축소

- v0.15.9에서 아이템 패널 가로 폭을 12px 줄였으나 여전히 넓다.
- **현재 아이템 패널의 좌우 여백을 각각 기존의 절반 수준으로 축소**하고, 그에 맞춰 패널 전체 너비도 줄인다.
- **아이템 슬롯 자체의 크기는 변경하지 않는다.** 아이템 크기 확대는 추후 별도 요청 예정이다.
- 2열 × 6행 기본 보관함, 초과 아이템 스크롤, 특수 예약 2칸, 휴지통/복원 기능을 유지한다.
- 테두리/광원과 스크롤바를 포함한 최소 필요 폭을 확인하고, 아이템이나 버튼이 잘리지 않도록 한다.
- 전장 크기, 7×8 좌표, 하단 대기석 10칸 구조를 변경하지 않는다.

## 구현 전 확인이 필요한 결정

1. **보급 골드 확률:** 2~3G 추가 지급의 발동 확률과 2G/3G 비율은 사용자가 지정하지 않았으므로 승인 전 임의 확정 금지.
2. **상점 잠금 세부 동작:** 잠금 중 수동 새로고침, 후보 구매 및 저장/불러오기 처리 방침은 현행 코드를 검토하고 충돌이 있으면 먼저 보고.
3. **6라운드 종료 분기:** 기존 종료/결산 흐름과 연결 방식 및 이어하기 이후 진행 규칙 확인.

## 회귀 테스트 및 완료 보고

- 도감 4종 진입, 기존 조합 표시 정상 작동
- 영입 후보의 2성/3성 예고가 실제 합성 결과와 일치
- 전장/대기석 보유 강조 및 추천 강조 공존
- 승리 체력 +2, 100 상한, 패배 체력 연출 유지
- 보급 골드 중복 지급 방지, 기존 보급/보스 보상 유지
- 라운드 중앙 안내의 정상 등장/해제
- 1회성 잠금과 자동 해제, 다음 라운드 후보 유지
- 장착 아이템 툴팁이 정보창 위에 정상 표시
- 6라운드 종료 팝업의 종료/계속 진행 동작
- 아이템 패널 축소 후 슬롯·스크롤·삭제·복원 정상 작동
- 저장/불러오기 및 기존 전투·경제·증강·합성 기능 회귀 테스트

완료 시 **구현/보류/추가 승인 필요 항목**, 수정 파일, 테스트 결과를 구분해 보고한다.
