# AUTOCHESS — 전장 중심 UI 리디자인 / Codex 실행 패키지

> 문서 상태: **구현 요청용 명세서** (미구현). UI 개편 작업명: `v0.12 UI 리디자인` (가칭).  
> 기준: 사용자가 승인한 판타지 전장 시안 + 이전 `AUTOCHESS_v0.12_UI_REDESIGN_SPEC_FOR_CODEX.md`.  
> **주의:** 사용자 화면 상단에는 `PROTOTYPE 0.14` 표기가 보인다. 이 문서의 `v0.12`는 작업명이지 현재 코드 버전이 더 낮다는 의미가 아니다. **실제 코드/패치노트의 최신 버전을 먼저 확인하고, 버전 번호를 되돌리지 말 것.**

## 1. Codex에 바로 붙여넣을 최종 요청문

```text
AUTOCHESS 프로젝트의 현재 최신 소스를 확인한 뒤, 첨부한 「AUTOCHESS — 전장 중심 UI 리디자인 / Codex 실행 패키지」의 요구사항에 따라 UI를 구현해 줘.

목표는 승인된 다크 판타지 콘셉트 이미지처럼 8×8 전장을 화면에서 가장 크게 보이게 하고, 좌측 조합과 우측 아이템 보관함을 반투명 오버레이 요약 패널로 옮기는 것이야. 조합 항목/아이템에 마우스를 올리면 상세 툴팁 또는 확장 패널이 표시되게 해 줘. 우측 하단의 테스트용 설정과 임시 규칙 안내는 상단 설정/더보기 메뉴 내부로 이동하고, 하단에는 기존 상점 5칸·새로고침·영입·전투 시작·딜량 진입점을 정돈해 줘.

게임 로직, 데이터, 전투, 경제, 증강, 조합, 아이템, 드래그/드롭, 저장 기능을 임의로 수정하거나 삭제하지 말아 줘. 디자인 시안은 배치/분위기의 참고 자료이며 시안에 표시된 임시 캐릭터·수치·아이템·버전은 실제 데이터로 덮어쓰지 마.

작업 전 현재 프로젝트 구조와 최신 버전을 확인하고, UI 관련 파일을 중심으로 변경해 줘. 완료 후 변경 파일, 구현 항목, 실행·검증 결과, 확인된 제한사항을 보고하고, 패치노트에 실제 구현된 내용만 반영해 줘. 기존 버전 번호보다 낮은 번호로 되돌리지 마.
```

## 2. 구현 범위: 작업용 압축 명세

### A. 화면 레이아웃 (필수)

1. **전체 화면형 전장:** 게임 플레이 화면의 상단 HUD와 하단 컨트롤을 제외한 가용 공간에서 **8×8 전장을 최대한 크게 중앙에 배치**. 전장과 겹치는 UI는 화면 양옆의 얇은 오버레이만 허용. `8×8`, 아군 아래 4줄 및 기존 배치 판정 유지.
2. **상단 HUD:** 게임명, 원정 HP, 난이도, 현재 스테이지 및 1~5 노드 진행 상황, 골드, 레벨/XP, 기존 주요 메뉴, 새 설정 메뉴를 한눈에 읽히도록 구성. 좁은 창에서는 필요한 정보가 사라지지 않도록 압축/접기.
3. **좌측 조합:** 반투명 요약 패널. 기본 상태에서는 현재 해당하는 조합 이름·아이콘·단계 카운트 및 활성 상태만 표시. **개별 조합 항목 hover/focus 시 우측 방향 상세 패널**에 설명, 단계별 효과, 현재 단계, 소속 유닛 표시. 조합 목록이 길면 내부 스크롤.
4. **우측 아이템:** 반투명 보관함 요약 패널. 기본 상태에서도 보유 개수, 아이템 슬롯, 특수 슬롯 두 칸을 인지할 수 있어야 함. **아이템 hover/focus 시 좌측 방향 상세 패널**에 이름, 티어, 스탯, 고유 효과 표시. 기존 장착·이전·보관함 회수·삭제 및 되돌리기 진입점 유지.
5. **상단 설정/더보기:** 우측 하단에 상시 보이는 테스트용 스위치(예: 시작 MP 100%, 유대 효과 테스트)와 임시 규칙 안내를 상단 펼침 메뉴/팝오버로 이동. 기존 옵션의 상태와 작동 방식은 유지.
6. **하단 조작바:** 상점 5칸, 새로고침, 동료 영입, 전투 시작을 기존 기능에 연결해 배치. 전투 시작을 가장 분명하게 강조. 아군 딜량 그래프는 좌하단 축약 패널 또는 펼침 버튼으로 유지.

### B. 스타일 (필수)

- **승인 시안의 분위기:** 다크 판타지 유적/전장, 어두운 남색·검정의 반투명 유리형 패널, 은은한 푸른색/보라색 외곽선, 황금색 주요 행동 강조.
- 배경보다 타일·유닛·텍스트의 **명료함이 우선**. 배경 이미지는 선택사항으로, 기존 에셋을 재사용하거나 CSS 처리할 수 있음. 시안 그대로의 외부 이미지가 필수 아님.
- 조합/아이템 상세창은 상점·캐릭터·드래그 대상과 충돌하지 않도록 레이어 우선순위와 화면 경계를 처리.
- 패널은 시각적으로 가볍고 비대하지 않아야 함. 애니메이션은 짧고 과하지 않게.

### C. 인터랙션 (필수)

- 조합/아이템 **hover + 키보드 focus**에서 상세 내용 확인 가능.
- 패널에서 툴팁으로 포인터를 이동해도 불필요하게 즉시 닫히지 않도록 처리.
- 터치/hover 미지원 환경에서는 클릭/탭으로 펼치기 및 닫기 제공.
- 캐릭터 클릭(정보), 드래그(이동·교체), 아이템 드래그(장착·이전·회수), 상점 영입/새로고침과 전투 시작이 변경 전과 동일하게 작동해야 함.
- 전투 중에도 중요한 정보가 가려지거나 조작이 막히지 않게 함.

### D. 적응형 레이아웃 (필수)

- **PC 우선**: 최소 1920×1080, 1600×900, 1366×768에서 확인.
- 낮은 높이의 브라우저 창에서도 하단 상점과 전투 시작 버튼이 잘리지 않게 함.
- 너비가 줄면 양옆 패널을 먼저 축소/접고 전장 공간을 우선 확보. 필요 시 별도 스크롤 영역/접기 사용.
- HUD·전장·하단바가 중첩되어 **필수 조작을 가리지 않게** 구현.

## 3. 기존 기능 보호 체크리스트

- [ ] 8×8 전장, 아군/적군 영역, 배치 제한 및 전투 진행 유지
- [ ] 유닛 클릭 상세 / 드래그 이동·교체 정상
- [ ] 조합 단계와 활성 상태 계산 및 상세 내용 정확
- [ ] 상점 5칸, 새로고침 비용, 동료 영입 정상
- [ ] 아이템 보관함, 특수 슬롯 2칸, 드래그 장착·회수·이전 정상
- [ ] 휴지통 삭제 및 마지막 삭제 되돌리기 정상
- [ ] HP·골드·레벨·XP·스테이지 표시가 실제 게임 상태와 일치
- [ ] 보급·보스·전투 결과·증강 선택 등 기존 팝업 흐름 정상
- [ ] 테스트 스위치가 상단 메뉴로 이동 후에도 실제 설정과 연결됨
- [ ] 저장/불러오기 및 새로고침 후 화면과 상태 일치
- [ ] 스테이지별 진행/코스트/전투/경제/아이템 효과 변경 없음

## 4. 작업 순서 권장

1. 현재 소스의 컴포넌트 계층, 화면 크기 처리, UI 상태 저장 방식과 최신 패치 버전 조사.
2. 상단 HUD·중앙 전장·하단 조작바로 레이아웃 골격 교체.
3. 조합/아이템을 반투명 양옆 오버레이로 이동하고 상세 hover/focus/클릭 구현.
4. 테스트 UI를 상단 메뉴로 옮기고 기존 이벤트 연결.
5. 드래그/드롭·팝업·툴팁의 z-index, 클릭/마우스 이벤트 충돌 해결.
6. 3개 PC 해상도에서 확인하고 기능 회귀 검증.
7. 실제 구현 결과에 맞게 패치노트 업데이트, 변경 파일/검증 보고.

## 5. 완료 판정 (Acceptance Criteria)

- [ ] 사용자의 승인 시안과 비슷한 **전장 우선 다크 판타지 UI**로 바뀜
- [ ] 전장이 현재 화면보다 충분히 크게 보이고, 플레이 영역이 화면의 주인공임
- [ ] 좌측 조합 요약 + 상세, 우측 보관함 요약 + 상세가 모두 작동
- [ ] 테스트용 규칙/설정의 기본 상시 노출이 제거되고 상단에서 접근 가능
- [ ] 상점·전투 시작·딜량·드래그 등 주요 기능이 유지됨
- [ ] 1920×1080, 1600×900, 1366×768에서 필수 UI가 잘리지 않음
- [ ] 저장·불러오기, 보급/전투/증강 흐름 회귀 문제가 없음
- [ ] 실제 코드 버전이 역행하지 않고 패치노트가 구현 내용과 일치함

> **상태: 초안 / 아직 구현 완료를 의미하지 않음.** 실제 코드 확인 후 완료된 항목만 남길 것. 아래 제목의 버전 번호는 작업명이며, 프로젝트의 실제 최신 번호에 따라 조정할 것.

### v0.12 (가칭) — 전장 중심 UI 리디자인

- 플레이 화면을 전장 중심으로 재구성하고 8×8 필드를 화면의 주요 영역으로 확대.
- 좌측 조합 목록을 반투명 요약 패널로 변경하고, 조합 항목에 마우스를 올리거나 포커스하면 단계·효과·소속 유닛 상세 정보를 표시.
- 우측 아이템 보관함을 반투명 패널로 재구성하고, 아이템 선택 시 티어·능력치·고유 효과 상세 정보를 표시.
- 상단 HUD에 체력·스테이지·골드·레벨·XP·메뉴를 정돈하고, 테스트 설정/임시 규칙을 상단 펼침 메뉴로 이동.
- 하단 상점 5칸, 새로고침, 동료 영입, 전투 시작 버튼과 딜량 정보 접근점을 재배치.
- PC 화면 크기에 따라 보조 패널이 축약되는 적응형 레이아웃을 적용.
- 기존 전투, 상점, 아이템 드래그, 저장 기능은 변경하지 않음.

## 8. 원칙과 주의사항

1. **현행 소스가 최우선:** 현재 버전/기능은 작업 시작 시 코드와 최신 패치노트에서 확인한다. 제공된 과거 v0.10 패치노트를 근거로 새 버전의 기능을 삭제하거나 이전 상태로 되돌리지 않는다.
2. **UI 변경과 게임 밸런스 분리:** 경제·전투·조합·증강·아이템 효과 수정은 이번 작업 범위 밖이다.
3. **시안은 시각 참고자료:** 시안에 그려진 임시 비용·아이템명·HP·레벨·버전 등을 실제 게임의 기준 데이터로 간주하지 않는다.
4. **미완료를 완료로 쓰지 않기:** 패치노트 초안은 구현 및 검증 후 확정한다.
5. **기존 상세 명세서와 병행:** 추가 세부 설명은 `AUTOCHESS_v0.12_UI_REDESIGN_SPEC_FOR_CODEX.md`를 참고하되, 충돌 시 이 문서의 현행 버전 보호 원칙을 우선한다.
