# AUTOCHESS v0.10 — 아이템40종/보급/보관함/패치노트

## 반영 내용
- 사용자 확인에 따라40종(I01~I40) 구현:1티어10종/2티어15종/3티어15종.
- 문서의 능력치/이름/효과를 등록하고 실제 전투에 연결했습니다. HP/MP/AS/치명타/회피/사거리와 복합 스탯을 장비 미리보기와 전투에 동일하게 적용합니다.
- 티어 테두리:1티어회색,2티어파랑,3티어노랑.10개 종류의 단순 SVG 아이콘을 사용합니다.
- 보관함 위 특수 슬롯2개는 예약 UI만 추가했습니다. 일반 아이템을 넣거나 별도 능력/획득 규칙을 만들지 않았습니다.
- 보관 중 아이템을 휴지통으로 드래그하거나 정보에서 버릴 수 있습니다. 마지막 삭제1건은 되돌리기가 가능하고 저장/불러오기에도 보존됩니다. 장착 중 장비는 먼저 회수해야 합니다.
- 기존 보관함은16칸부터 자동 확장하는 방식입니다. 이번에는 새 고정 용량 제한을 추가하지 않았습니다.
- 새 원정은 무작위 서로 다른1코스트2명+2코스트1명, 시작7G로 변경했습니다. 기존 세이브의 동료/골드는 유지합니다.

## 문서와 직접 요청이 충돌한 부분
- 최초 메시지의45종은 사용자 답변으로40종 정정 완료.
- 문서는3티어 중복도 허용하도록 적혔지만, 직접 요청을 우선해 같은3티어 ID만 중복 장착 금지했습니다.1/2티어 동일 장비는 중복 가능, 다른3티어3개는 가능하며 총3칸을 유지합니다.
- 기존 검(sword)/갑옷(armor)/수정(crystal)은10스탯 효과와 기존 ID로 보존했습니다. 신규 보상 풀은40종만 사용하며 구형 장비도 장착/해제/회수/삭제할 수 있습니다.

## 보급/보스/골드
- 보급 진입 시4개를 제시하고 슬롯2개를 선택한 뒤 확정해야 지급합니다. 한 제시 화면 내 ID 중복을 피하며 각 슬롯의 티어는 문서의 확률로 독립 추첨합니다.
- 제시/선택을 라운드 키로 저장하고 수령은 기존 completedRounds 정산 장부로 보호합니다. 새로고침/재진입/중복 클릭으로 재추첨/중복 수령되지 않습니다.
- 보스 승리 확정 장비1개:상위구간1=T1,2~4=T2,5이상=T3. 패배 시 확정 장비 없음.
- 기존 보스40%아이템/60%골드의 아이템 분기를 확정 아이템으로 대체했습니다. 골드가 추가 지급되는 기존60% 확률과 금액(5/7/9/11/13/15G, 이후15G)은 그대로입니다.
- 일반3/1G,보스5/3G,연승최대5G,정산 전10G당 이자1G/최대5G,보너스 몬스터40%아이템/60%3~5G를 변경하지 않았습니다. **전투 골드 보상 로직과 분포는 유지했습니다.** 새 원정 시작금만 요청대로7G입니다.
- 문서에 없는 보너스 몬스터 아이템 경로는 기존 균등 추첨을 유지해 새40종을 균등 추첨합니다. 보급/보스의 티어 제한은 해당 두 경로에만 적용합니다.

## 고유 효과 연결/세부 가정
- I26 기본 공격 적중에서 주변1칸 다른 적 최대2명에 AD60% 마법 피해.
- I27 모든 활성23명 스킬에25% 추가 발동을 연결했습니다. 대상이 죽으면 생존 적을 다시 고르며 마나를 추가 소모하지 않습니다. 소환 상한/HP비용/치유/범위 등 원래 스킬 동작은 유지합니다.
- I28 치명적 피해 직전 HP1/최대HP30% 보호막4초, 전투당1회.
- I29 실제 HP 피해 기반 기본 공격 흡혈20%. 초과피해/흡수된 피해는 포함하지 않습니다.
- I30 시전3초 후 MP최대치30% 회복, 쿨다운8초. 사망/전투 종료 후 미발동.
- I31 소유자 소환수만 기본 공격력30%/지속40% 강화. 독/사망 폭발 등 원래 스킬 수치는 바꾸지 않았습니다.
- I32 화상은 중첩 대신4초 지속 갱신, 매초 AP25%. 기존 상태 갱신 정책을 유지합니다.
- I33 대상별3회 적용 후1초 기절/카운트 초기화. 같은 대상은 시전자별로 관리합니다.
- I34 공격 직전 HP25% 이하 판정.
- I35 치유 스킬만30% 강화, 유효 치유량(오버힐 제외)의25% 보호막3초. 일반 흡혈은 치유 스킬로 취급하지 않습니다.
- I36 회피 후 AS20%4초, 쿨다운6초.
- I37 자기 자신/기존 맨해튼 인접1칸 아군에 최대HP15% 보호막6초.
- I38 첫 기본 공격부터1중첩으로 계수하고 최대8. 대상 변경은 초기화 후 새 공격1중첩입니다.
- I39 실제 스킬 HP 피해35%를 추가 마법 피해로 적용합니다. 한 시전 내 동일 출발 대상/동일 추가 피격 대상에 각1회만 적용하여 광역/다단히트의 과도한 중복을 막습니다.
- I40 처치마다 AD/AP각5%,최대25%로 가산 적용. 전투 종료 후 원래 캐릭터/장비 데이터는 바뀌지 않습니다.
- ITEM_PROC 출처 태그와 깊이 가드로 추가 스킬/추가 피해/아이템 화상의 다른 고유 효과 발동을 차단했습니다. 장비의 기본 능력치는 항상 적용됩니다. 중복된 고유 효과 ID가 입력돼도 효과는1회만 활성화됩니다.
- 모든 임시 중첩/쿨다운/예약/생존1회는 Battle 객체 안에서만 관리해 다음 전투마다 초기화합니다.
