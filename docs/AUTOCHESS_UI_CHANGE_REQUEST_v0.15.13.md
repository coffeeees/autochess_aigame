# AUTOCHESS — Codex UI 수정 요청서

- 기준 버전: v0.15.12
- 범위: UI/이미지 표시 변경만
- 상태: 사용자 요청사항 정리 (미구현)
- 주의: 본 문서의 이미지 파일은 MD에 포함되지 않으므로 PNG 원본을 별도로 전달해야 함.

## 1. 변경 범위와 우선 원칙

- 아이템 패널 자체의 크기·위치·테두리·배경은 유지한다.
- 전장의 7열×8행 논리 격자, 현재 화면의 가로로 긴 타일 비율(제공 스크린샷 기준 약 1.88:1)은 유지한다. 전장 원본 PNG와 격자 정렬을 변경하지 않는다.
- 전투, 경제, 영입 확률, 합성, 아이템, 장비, 저장, 증강 및 AI 규칙을 변경하지 않는다.
- 사용자가 제공한 UI 참고 이미지는 디자인 참고용이며, 기존 정상 동작을 유지한다.

## 2. 아이템 패널 내부 슬롯: 1:1 정사각형

- v0.15.12에서 44×28px로 설정된 일반 아이템 칸, 빈칸, 특수 예약 2칸을 모두 정사각형(가로:세로 = 1:1)으로 변경한다.
- 권장 초기값은 36×36px이며, 실제 레이아웃에 맞춰 조정해도 반드시 정사각형을 유지한다. 이 크기는 확정 치수가 아니라 제안값이다.
- 일반 보관함의 2열×6행 기본 12칸, 초과 아이템의 하단 확장 및 스크롤을 유지한다.
- 아이콘, 수량/번호 표시를 정사각형 칸 안에 맞춰 정렬한다. 특수칸과 일반칸의 정렬을 맞춘다.
- 휴지통/되돌리기 버튼과 기능은 유지한다. 버튼 크기까지 정사각형으로 변경할 필요는 없다.
- 아이템 장착·이전·회수·삭제·복원·툴팁·저장 규칙은 그대로 유지한다.

## 3. 캐릭터 이미지 임시 적용 — C01 녹스

| 파일명 | 적용 화면 | 처리 |
| --- | --- | --- |
| `C01_녹스_썸네일02.png` | 대기석, 동료 영입 | 캐릭터 이미지 뒤에 코스트별 그라데이션 배경 적용 |
| `C01_녹스.png` | 도감 캐릭터 상세 | 원본 이미지를 사용하며 임의 재가공하지 않음 |

- 두 PNG 파일은 사용자가 Codex에 MD와 함께 별도 전달한다.
- 캐릭터 이미지는 임시 적용이며 향후 다른 캐릭터도 동일한 이미지 슬롯 구조로 쉽게 교체할 수 있게 한다.
- 이미지 원본의 비율을 유지하고 캐릭터의 얼굴과 주요 부분이 불필요하게 잘리지 않도록 표시한다.
- 첫 번째 PNG의 투명한 부분 뒤에 배경을 CSS 등 별도 레이어로 적용한다. 원본 이미지 파일에 배경을 영구 합성하지 않는다.
- C01의 실제 코스트는 현재 게임 데이터에 정의된 값을 사용한다. 이미지 작업을 위해 코스트·능력치·스킬·ID를 변경하지 않는다.

### 코스트별 배경색

| 코스트 | 배경 그라데이션 |
| --- | --- |
| 1 | 회색 |
| 2 | 초록색 |
| 3 | 파란색 |
| 4 | 보라색 |
| 5 | 노란색 |

- 그라데이션의 구체 색상값과 방향은 기존 다크 판타지 UI의 가독성에 맞게 정하되, 모든 캐릭터와 화면에서 동일 코스트 색상 규칙을 재사용한다.

## 4. 동료 영입 UI 개편

참고: 사용자가 제공한 `동료 영입 캐릭터 상점 UI(1).png`의 레이아웃과 시각적 계층을 디자인 기준으로 한다. 참고 이미지 자체를 게임 UI에 붙여 넣지 말고 실제 HTML/CSS UI로 구현한다.

### 상단 영역

- 기존 '원본 확률표' 버튼/펼침 영역을 제거한다.
- '등장 확률'이라는 문구는 삭제한다.
- 현재 레벨과 코스트별 확률 수치(예: 1G 65%, 2G 25%, 3G 10%)는 유지한다. 확률 수치는 현재 게임 계산 결과를 사용하며 임의 고정하지 않는다.
- 상점 잠금/해제, 새로고침 및 비용 표시, 닫기 버튼의 기능을 유지한다.

### 영입 카드

- 5개 후보 카드에 캐릭터 이미지, 이름, 종족/직업/특성 정보를 표시한다.
- 코스트는 카드의 별도 `1G`/`2G` 등의 숫자 배지 대신 이미지 뒤의 코스트별 그라데이션 배경색으로 구분한다. **이는 카드의 코스트 시각 표시를 변경하는 것이며 실제 구매 비용과 상단 확률 수치를 제거한다는 뜻이 아니다.**
- 추천 대상으로 강조해야 할 특성/유대가 있으면 해당 속성 칸의 **글자를 노란색**으로 강조한다.
- 추천 조건에 해당하는 카드의 외곽 테두리는 참고 이미지와 같은 **초록색/청록색 계열 발광**으로 강조한다.
- 이미 보유 중인 캐릭터는 **기존 보유 상태 테두리 표시를 유지**하고 카드 안에 `보유 중` 문구를 표시한다.
- 추천과 보유 중이 동시에 해당할 경우, 추천 발광 및 보유 표시가 서로 가려지지 않도록 공존시킨다. 기존 보유 식별 규칙을 삭제하지 않는다.
- 기존 구매 후 2성/3성 합성 예고 별 표시를 유지한다.
- 이미지/텍스트가 겹치지 않도록 하단 정보 영역에 적절한 반투명 배경을 사용할 수 있다.

### 기능 유지

- 상점 후보 5칸, 현재 레벨별 실제 등장 확률, 유료 새로고침 2G(기존 비용 변경 효과가 있으면 그 효과 우선), 상점 잠금 및 해제 조건을 유지한다.
- 추천 유대 최대 3개, 추천 강조의 확률 비변경, 이미 3성 보유한 ID의 후보 제외, 판매 후 복귀 규칙을 유지한다.
- 구매·매진칸·자동 합성·연쇄 합성·보유 판정·저장·불러오기를 유지한다.

## 5. 도감: 코스트별 구분선

- 도감의 캐릭터 목록에서 **1·2·3·4·5코스트 그룹 사이에 시각적 구분선**을 추가한다.
- 구분선에는 해당 그룹의 코스트 색상(1 회색, 2 초록, 3 파랑, 4 보라, 5 노랑)을 은은하게 반영한다.
- 각 코스트 그룹이 쉽게 식별되도록 간결한 코스트 표기를 구분선 부근에 표시할 수 있다. 과한 장식이나 큰 여백은 추가하지 않는다.
- 현재 캐릭터 목록의 정렬·검색/필터·잠금 상태·선택·상세 보기 등 기존 동작을 훼손하지 않는다. 현재 정렬/필터로 코스트가 섞여 표시되는 경우, 구분선이 잘못된 그룹을 가리키지 않도록 현재 화면 구조에 맞게 처리한다.
- 도감 상세의 C01 녹스 이미지는 `C01_녹스.png`를 사용한다.

## 6. 검증 및 완료 보고

1. 아이템 일반/빈칸/특수 슬롯이 모든 주요 화면 크기에서 정사각형인지 확인한다.
2. 전장 원본 이미지, 7×8 칸 정렬 및 현재 타일 비율이 변경되지 않았는지 확인한다.
3. 녹스 썸네일이 대기석·영입에, 별도 이미지가 도감에 표시되는지 확인한다.
4. 코스트별 그라데이션이 일관되게 적용되는지 확인한다.
5. 추천 특성 노란 글씨, 추천 카드 초록 발광, 보유 중 문구/기존 테두리가 각각 및 동시 상태에서 정상 표시되는지 확인한다.
6. 영입 상단에서 '원본 확률표'와 '등장 확률' 문구가 제거되고 실제 확률 수치는 남아 있는지 확인한다.
7. 도감의 코스트 그룹별 구분선이 정상 표시되는지 확인한다.
8. 구매·새로고침·잠금·합성·장비 드래그·저장/복원 및 기존 게임 판정에 회귀 문제가 없는지 확인한다.
9. 변경 파일과 테스트 결과를 보고하고, 변경사항을 프로젝트 문서/패치노트에 반영한다. 기존 이력은 삭제하지 않는다.
