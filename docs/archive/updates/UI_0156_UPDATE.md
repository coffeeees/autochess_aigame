## 구조와 좌표

풍경 배경은 게임 화면 전체를 원본 비율의 cover로 채웁니다. 체스판은 배경과 독립된 가운데 레이어입니다. 원본1672×941 PNG를 변경하지 않고 투명 여백만 CSS 뷰포트(원본좌표x335.5,y0,w1000,h925)에서 제외합니다. 석조 테두리는 입력 칸이 아닙니다. 보드 높이/위치는 `--board-art-height`, `--board-offset-x`, `--board-offset-y`로 조절하며 배경 크기와 독립적입니다.

세로 경계는 x480/582.5/684/785.5/887/988.5/1089.5/1191, 가로 경계는 y89/181.5/272.5/363/455/546.5/637/729/823입니다. 이미지의 1~3px 간격 차이에 맞춰 CSS grid 트랙을 설정합니다. 게임 규칙은7열×8행/아군 아래4행을 유지합니다. 유닛·투사체·피해 숫자는 기존 실제 셀 중심 측정을 사용하고 전투 중 크기 변경 시 다시 측정합니다.

## 검증 결과

- 체스판 PNG RGBA8 확인. 바깥 모서리/측면의 샘플 알파0이며 총763,483개 완전 투명 픽셀이 있습니다. 검정 배경이 구워진 이미지가 아닙니다. 원본의 부분 투명/안티앨리어싱도 그대로 유지합니다.
- 이미지에서 세로 경계8개/가로 경계9개를 검출하여7×8을 확인했습니다. 실제56칸 경계와 이미지 실측 경계 간 오차는1920에서0.02px,1366에서0.04px 이내입니다.

- 적 진영 드래그 배치를 차단하고 기존 안내를 표시했습니다. 아군 배치3/4→4/4 및31번/30번 동료 UID4/1 교체를 확인했습니다.
