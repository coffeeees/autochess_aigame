로컬 QA 서버에서 Worker 스크립트 응답에만1000ms 지연을 주었습니다. 실제 배포 소스에는 지연 코드/타이머가 없습니다.

1/2/4배속,다중 틱 이벤트 누락 방지,준비 중 일시정지·숨김·복귀·Worker 오류/생성 실패는 자동 검증했습니다. 실제 브라우저4배속은0→0.2→0.4초로 진행했고, 신규6인 고코스트 실제 전투는10.4초에 정상 승리/정산했습니다. OS 실제 창 최소화·기기별 GPU/FPS·사용자 원래 네트워크에서의 현상 동일성은 미확인입니다. 설정의 전투 시작 진단 로그로 해당 환경의 단계 시간/Worker timing/longtask를 내려받을 수 있습니다. 로그에는 게임 저장/계정 정보가 없습니다.
