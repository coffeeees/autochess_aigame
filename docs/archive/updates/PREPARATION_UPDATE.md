# AUTOCHESS 0.14 · 준비 단계 수정

- 영입 후 카드 DOM이 갱신되면서 클릭 대상이 팝업에서 분리되고, 문서의 바깥 클릭 판정이 이를 외부 클릭으로 오인하던 버그를 수정했습니다. 클릭 시작 경로(`composedPath`)로 내부 클릭을 판정하여 연속 구매/새로고침 후에도 상점을 유지합니다. 기존 닫기 버튼과 실제 바깥 클릭은 유지합니다.
- 새 원정의 랜덤 동료 1코스트2명·2코스트1명은 서로 다른 대기석 칸에 배치합니다. 7G 시작 및 기존 세이브의 배치는 유지합니다.
- 전투 시작 시 실제 배치 한도(P12 포함)보다 인원이 적으면 현재/최대 인원, 남은 자리와 함께 재설정/진행을 묻습니다. 보급에는 경고를 띄우지 않습니다.
- ‘이번 원정에서 다시 묻지 않기’는 진행 확정 시 원정 저장 데이터에 반영하고 새 원정에서 초기화합니다. 취소/바깥 클릭으로는 전투를 시작하거나 생략 설정을 바꾸지 않습니다.
- 전장이 완전히 비어 있어도 진행을 고르면 기존 결산 경로로 즉시 패배 처리합니다. 확인창에 해당 결과를 명시합니다. 중복 보상은 지급하지 않습니다.
- 기존0.12 수정과0.13의 증강36종을 포함한 통합 업데이트입니다.

검증: 전체10개 묶음 **173개 테스트 통과**. 실제 브라우저에서 시작 전장0명/대기석3명/7G, 보급 진행, 증강 확정, 연속2회 영입 후 상점 유지, 0명/1명 배치 경고, 재설정 후 드래그 배치, 확인 후 전투, 새로고침/이어하기 후 경고 생략 유지까지 확인했습니다. 콘솔 오류0개입니다.

주요 변경: `dist/content-ui.js`, `dist/prototype.js`, `dist/progression.js`, `dist/preparation.js`, `dist/stage-ui.js`, `dist/content.css`; 버전/패치노트 및 회귀 검사 갱신. 전투 수치·상점 확률·장비·증강·기본 보상/이자/연승 공식은 유지합니다.
