# AUTOCHESS — v0.15.15 이후 수정 및 VFX 적용 요청서

- 대상: 현재 AUTOCHESS 웹게임의 실제 최신 코드
- 기준: 사용자가 전달한 v0.15.15 패치 이후 신규 요청
- 첨부 참고: `image(20261117-085031).png` (아이템 패널), `image(20261117-085110).png` (조합 패널), `AUTOCHESS_VFX_CODEX_IMPLEMENTATION(1).md` (기존 VFX 상세 사양)
- **이번 작업은 아래 UI 수정 3건과 VFX 적용 1건만 수행**한다. 이전 패치에서 완료된 사항을 신규 작업으로 재작성하거나 되돌리지 않는다.

## 1. 전투 결과창이 닫힌 후 적 배치

### 문제
전투 결과창이 표시되는 동안 다음 스테이지의 적 유닛이 먼저 전장에 배치되어 보이는 문제가 있다.

### 요구사항
- 전투 결과창이 열린 상태에서는 **다음 스테이지 적 유닛을 전장에 표시하거나 배치하지 않는다**.
- 플레이어가 결과창을 닫고 다음 단계로 넘어가는 흐름이 확정된 **이후** 다음 스테이지 적 배치를 수행한다.
- 내부적으로 다음 적 정보를 미리 생성하는 것은 가능하지만, 결과창이 닫히기 전에는 전장 렌더 상태에 노출되지 않아야 한다.
- 결과창 닫기/스테이지 전환/적 배치가 중복 호출되지 않도록 한다. 보급·보스·라운드 전환·저장/불러오기·백그라운드 복귀도 확인한다.
- 결과창 표시 중 기존 전투의 잔여 유닛 처리와 다음 스테이지의 적 배치를 구분하고, 전투 결과 및 보상은 변경하지 않는다.

**완료 기준:** 결과창이 열려 있는 동안 다음 스테이지 적이 보이지 않고, 결과창을 닫은 뒤에만 새 적이 나타난다.

## 2. 아이템 패널 내부 불필요한 빈 공간 제거

### 문제
첨부 스크린샷에서 아이템 패널 하단, 아이템 슬롯 영역과 휴지통/복원 버튼 주변에 불필요한 세로 빈 공간이 많다.

### 요구사항
- 실제 아이템 보유량과 슬롯 레이아웃을 고려하여 패널 내부 여백·높이·스크롤 영역·버튼 배치를 재조정한다.
- **내용에 맞게 패널 높이가 자연스럽게 줄어들도록** 하되, 보관함이 길어질 때는 기존 스크롤을 유지한다.
- 상단 특수 슬롯 2개, 일반 아이템 2열 배열, 휴지통·복원 버튼을 유지한다.
- 슬롯 크기를 무조건 다시 바꾸지 말고 현재 화면에서 적절한 크기를 유지하며 공간 배분을 수정한다.
- 딜량 그래프 표시 시 패널 하단 잘림이 다시 발생하지 않도록 높이 제약과 `overflow`를 함께 확인한다.
- 패널 접기/펼치기와 다양한 해상도에서 슬롯·버튼이 잘리거나 과도하게 벌어지지 않게 한다.

**완료 기준:** 첨부 화면과 비교하여 불필요한 하단 여백이 눈에 띄게 줄고, 모든 슬롯·버튼에 접근할 수 있다.

## 3. 조합 패널 하단 콘텐츠 돌출·잘림 수정

### 문제
첨부 스크린샷에서 조합 패널 하단의 다음 유대 항목 텍스트·아이콘이 패널 바깥으로 튀어나오거나 테두리에 걸쳐 보인다.

### 요구사항
- 조합 목록의 스크롤 컨테이너, 하단 패딩, 높이 계산, `overflow`, 테두리/모서리 클리핑을 점검한다.
- 유대 목록의 마지막 행이 패널 내부에서 온전히 보이도록 하고, 패널 바깥으로 텍스트·아이콘·선택 효과가 돌출되지 않게 한다.
- 스크롤할 때 첫 행과 마지막 행을 완전히 확인할 수 있어야 한다.
- 접기/펼치기 애니메이션, 패널 리사이즈, 유대 개수 변동 및 화면 높이 변화에도 문제가 없어야 한다.
- 유대 효과, 활성화 판정, 별표 버튼 등의 동작은 변경하지 않는다.

**완료 기준:** 스크롤 위치와 관계없이 조합 패널 경계 밖으로 목록 내용이 노출되지 않으며 마지막 항목도 온전히 접근 가능하다.

## 4. 기존 VFX 문서 구현 — 적용 대상 제한 변경

### 원본 사양
첨부된 `AUTOCHESS_VFX_CODEX_IMPLEMENTATION(1).md`를 **이펙트의 외형·파티클·광원·애니메이션·좌표·동기화·성능·테스트 기준의 원본 사양**으로 사용한다.

### 이번 요청에서 우선하는 적용 규칙
원본 문서의 `yellow`를 녹스 등의 **기본 원거리 공격**에 시험 적용한다는 설명은 **이번 요청으로 대체**한다.

| 테마 | 적용 대상 | 적용 이벤트 | 적용하지 않을 대상 |
|---|---|---|---|
| `gray` 회색 | 원거리 일반 공격을 수행하는 캐릭터 | 해당 캐릭터의 **일반 공격 발사·비행·실제 명중** | 근접 일반 공격, 스킬 공격, 원거리 공격을 하지 않는 캐릭터 |
| `yellow` 노란색 | **녹스(Nox)** | 녹스의 **스킬 사용에 의해 실제 발사·충돌하는 투사체 이벤트** | 녹스의 일반 공격, 다른 캐릭터의 일반 공격/스킬 |

- **노란색은 녹스 스킬 전용**이다. 녹스의 일반 공격이 원거리 일반 공격에 해당한다면 회색 테마만 사용한다.
- `gray` 적용 대상을 직업 이름(궁수 등)만으로 임의 판단하지 말고 **실제 일반 공격 방식이 원거리인지** 기존 캐릭터 데이터·전투 이벤트를 확인하여 판정한다. 원거리 마법사 등도 실제 일반 공격이 투사체라면 포함될 수 있다.
- `yellow`는 녹스의 정확한 캐릭터 ID 및 스킬 발동 이벤트를 기존 데이터에서 확인해 연결한다. 캐릭터 이름 문자열만으로 느슨하게 매칭하지 않는다.
- 녹스 스킬이 단발 투사체인지, 다중 투사체인지, 즉시 타격인지 실제 구현을 확인한다. 원본 문서의 발사→비행→명중 표현을 **실제 스킬 판정에 맞춰** 연결하며, 없는 투사체·명중 판정을 새로 만들어 게임 규칙을 바꾸지 않는다. 매핑이 불가능하면 그 사유를 보고한다.
- 동일 공격에서 회색·노란색이 중복 생성되지 않게 한다. 스킬 사용 순간과 실제 명중 이벤트의 중복 발동도 방지한다.
- 적/아군 모두에 적용할지는 현재 일반 공격 VFX 정책을 우선 확인하되, 요청 범위를 임의로 확대하지 말고 적용 대상을 결과 보고에 명시한다.

### 유지할 VFX 디자인
- 투사체: 단순 직선 막대. 화살촉, 깃털, 탄피, 꼬리/트레일 없음.
- 발사와 실제 명중 순간에 작은 정사각형 도트 파티클과 강한 확산 광원.
- 픽셀은 선명하게 유지하고 광원만 부드럽게 퍼지도록 처리.
- 파티클은 페이드아웃이 아니라 **개별 도트가 수명 종료 시 즉시 사라져 개수가 줄어드는 방식**.
- 원본 문서의 색상 팔레트와 권장 파티클 수·수명·시각 동기화 원칙 유지.
- `requestAnimationFrame` 기반 시각 렌더링과 전투 판정을 분리하고, 현재 백그라운드 전투 Worker/경과시간 진행 로직을 손상시키지 않는다.
- 회피/MISS에 명중 이펙트를 표시하지 않는다. 전투 종료·일시정지·탭 복귀 시 잔여 이펙트를 정리한다.

### VFX 검증
1. 일반 원거리 딜러 기본 공격: 회색 발사·비행·명중 효과가 정상 출력된다.
2. 근접 딜러 기본 공격: 회색/노란색 효과가 나오지 않는다.
3. 녹스 일반 공격: 노란색 효과가 나오지 않는다. 원거리 기본 공격이면 회색만 출력된다.
4. 녹스 스킬: 스킬의 실제 투사체/명중 구조에 맞게 노란색 효과가 나온다.
5. 다른 캐릭터의 스킬: 노란색 효과가 나오지 않는다.
6. 다수 동시 공격, 방향 전환, MISS, 일시정지, 백그라운드 복귀, 전투 종료, 화면 크기 변경을 테스트한다.
