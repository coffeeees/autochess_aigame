# AUTOCHESS — 추가 UI 개선 및 공통 알림 정리 작업 지시서

- **기준 버전:** v0.15.7
- **대상:** Codex
- **범위:** 이번에 새로 요청한 UI 변경 8개 + 공통 알림 41개 처리
- **원칙:** 기존 전투·경제·아이템·저장 규칙은 유지한다. 변경이 필요한 부분은 아래 명시된 UI 및 전투 시작 가능 여부로 한정한다.

## 1. 신규 UI 수정 요청 (8개)

### 1-1. 캐릭터 자동 합성 연출
- 동일 캐릭터 3개가 합성될 때, 합성에 소모되는 나머지 2개 캐릭터가 **합성 기준 캐릭터를 향해 슬라이드 이동**하며 합쳐지는 연출을 추가한다.
- 합성 결과로 **전장에 배치된 해당 캐릭터의 성급이 올라가는 경우**, 전장의 그 캐릭터를 합성 연출의 중심으로 사용한다.
- 그 외에는 **대기석에서 가장 왼쪽에 있는 해당 캐릭터**를 중심으로 사용한다.
- 합쳐지는 순간 **광원(발광) 효과**를 추가한다.
- 합성 결과, 캐릭터 수, 성급 계산 등 기존 합성 로직은 유지한다. 연출 도중 입력이나 상태가 꼬이지 않도록 처리한다.

### 1-2. 준비 단계의 진영별 테두리
- **준비(대기) 단계**에는 적 진영 타일의 테두리를 **빨간색**, 아군 진영 타일의 테두리를 **파란색**으로 표시한다.
- 실제 전장 구조인 **7열 × 8행**, 아군 하단 4행의 배치 판정은 변경하지 않는다.
- 전투 단계의 테두리 표시 방식은 기존 동작을 우선 유지한다.

### 1-3. 레벨업 버튼 연출
- 레벨이 상승했을 때 하단 왼쪽 **레벨/XP 버튼**에 짧은 **발광 효과**와 **가볍게 흔들리는 모션**을 적용한다.
- XP만 구매하고 레벨이 상승하지 않았다면 레벨업 연출은 실행하지 않는다.
- 레벨/XP 구매 비용 및 레벨업 규칙은 변경하지 않는다.

### 1-4. 배치 인원 표시
- **대기석 패널 바로 위 중앙**에 현재 배치 인원을 `n / n` 형태로 표시한다.
- 앞의 숫자는 현재 전장에 배치된 아군 수, 뒤의 숫자는 현재 허용되는 최대 배치 수다.
- **굵고 강조된 노란색 글씨**를 사용한다.
- 레벨 변화, 배치·회수·판매·합성 등으로 값이 달라질 때 즉시 갱신한다.
- 기존 HUD와 겹치지 않도록 배치한다.

### 1-5. 빈 전장 전투 시작 차단
- 전장에 아군 캐릭터가 **0명**이면 전투 시작을 허용하지 않는다.
- 전투 시작 버튼은 비활성화하거나, 시작 요청을 명확히 차단한다.
- 플레이어가 이유를 알 수 있도록 버튼 상태 등으로 안내하되, **삭제 대상 공통 알림 T38을 다시 추가하지 않는다**.
- 아군이 1명 이상 배치되면 기존 전투 시작 조건에 따라 동작한다.

### 1-6. 공통 알림 표시 UI 변경
- 공통 알림을 **대기석의 오른쪽 상단**에 **가로 바 형태**로 표시한다.
- 알림은 **슬라이드 애니메이션**으로 등장한다.
- **3초 후 자동으로 사라지며**, 퇴장 시에도 자연스러운 전환 효과를 적용한다.
- 알림의 발생 여부는 아래 **2. 공통 알림 정리** 기준을 따른다.
- 모달, 툴팁, 인라인 안내는 공통 알림과 구분하여 기존 동작을 유지한다.

### 1-7. 아이템 보관함 슬롯 구성
- 아이템 보관함의 **일반 아이템 슬롯**을 **가로 2열 × 세로 6행(총 12칸)**으로 변경한다.
- 기존 아이템 보유·장착·이동·삭제·복원 규칙은 변경하지 않는다.
- 기존 슬롯 수보다 표시 가능한 슬롯 수가 줄어들 경우 **보유 아이템을 삭제하거나 유실시키지 말고**, 초과 아이템 표시 및 접근 방법을 먼저 확인해 안전하게 구현한다.
- 일반 슬롯 외 별도 슬롯이 있다면 그 용도와 동작은 유지한다.

### 1-8. 전체 패널 테두리 개선
- 화면의 주요 UI 패널 테두리를 **현재보다 약간 두껍게** 조정한다.
- 테두리에 **은은한 발광 효과**를 적용해 패널 구분을 강화한다.
- 과도한 광원으로 텍스트나 버튼의 가독성이 떨어지지 않도록 한다.
- 패널의 기능 및 기본 배치 구조는 유지한다.

### 2-3. 수정 검토 (1개 — 구현 전 확인 필수)

**T28 — 아이템 삭제 요청 거절**

- 기존 문구: `장착 중인 아이템은 먼저 보관함으로 회수하세요.`
- Codex는 현재 T28이 발생하는 **실제 코드 조건**과 가능한 실패 원인을 먼저 조사한다.
- 오류 원인에 맞는 문구 또는 표시 조건 변경안을 제시한다.
- **사용자의 승인 없이 T28 문구나 발생 조건을 임의 변경하지 않는다.**

## 3. 구현 시 주의사항

1. 알림 제거로 인해 캐릭터 합성·레벨업·아이템 복원 등 실제 기능이 제거되지 않도록 한다.
2. 합성/레벨업은 공통 알림 대신 이번에 요청한 시각 효과로 결과를 전달한다.
3. 빈 전장 전투 시작 차단은 신규 요청사항으로 반영하되, 그 외 전투 판정·보상·경제 규칙은 유지한다.
4. 알림 바가 대기석, 영입 버튼, 전투 시작 버튼, 배치 인원 표시와 겹치지 않도록 한다.
5. 변경된 UI는 1920×1080 화면에서 우선 확인하고, 다른 창 크기에서도 주요 기능이 가려지지 않는지 검증한다.
6. 작업 완료 패치노트에는 **이번 수정사항만 별도 구역으로 정리**하고, 알림 41개 처리 결과 및 T28 보류 여부를 명시한다.

## 4. 검증 체크리스트

- [ ] 합성 시 정확한 대상에게 2개 캐릭터가 슬라이드되고 발광한다.
- [ ] 전장 합성 대상과 대기석 왼쪽 합성 대상의 우선순위가 의도대로 작동한다.
- [ ] 준비 단계 적/아군 진영 테두리가 각각 빨강/파랑으로 표시된다.
- [ ] 실제 레벨 상승 때만 레벨 버튼 발광·흔들림이 실행된다.
- [ ] 배치 인원 `n / n`이 정확하게 실시간 갱신된다.
- [ ] 빈 전장에서는 전투를 시작할 수 없다.
- [ ] 공통 알림이 대기석 우측 상단에 슬라이드 등장하고 3초 뒤 사라진다.
- [ ] 공통 알림 유지 13개·삭제 27개가 지정대로 처리된다.
- [ ] T28은 조사 결과와 수정 제안만 보고하고, 승인 전 변경하지 않는다.
- [ ] 아이템 슬롯이 2열×6행이며 기존 아이템이 유실되지 않는다.
- [ ] 주요 패널 테두리가 약간 두꺼워지고 은은하게 발광한다.
- [ ] 기존 전투·경제·아이템·저장 기능에 회귀 오류가 없다.
