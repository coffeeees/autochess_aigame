## 플레이 / 기능 확인

- 시작 동료 C03·C01·C05. 상점은 C01~C12만 무작위 추출하며 모두 1G입니다.
- 캐릭터 도감의 무료 테스트 영입으로 원하는 1코스트를 바로 가져올 수 있습니다. 높은 코스트는 속성만 표시하고 이름·스킬·능력치를 만들지 않았습니다.
- 대기석에서 유닛 선택 → 전장 아래 네 줄 클릭. 유닛끼리 클릭하면 교체, 빈 대기석 클릭 시 회수합니다. 최대 10명.
- ‘시작 MP 100%’를 켜면 12개 스킬을 빠르게 시험할 수 있습니다. 기본은 MP 0입니다.
- ‘실험용 유대 수치 효과’는 기본 OFF. OFF에서도 모든 유대의 단계 판정과 시작 진형 스냅샷은 정상 동작합니다.
- 유대 목록에는 실제 배치된 유대만 표시합니다. 전체 보기에서 종족 9 / 직업 9 / 특성 10 및 모든 단계를 확인합니다. 🔒는 현재 1코스트 풀로 달성 불가능한 단계입니다.
- 전투 중 유닛 클릭 → HP/MP·능력치·스킬·상태·유대. 전투 아래 디버그 표와 기록에서 모든 유닛과 소환수를 확인합니다. 종료 후 표를 클릭하면 직전 전투 정보가 열립니다.
- 전투 결과창은 기본 보상·이자·총 획득 골드·현재 골드·체력·사용한 스킬을 표시합니다.
- 이전 일러스트판과 저장 키를 분리했습니다. 이 버전은 `starlight-onecost-v1`을 사용합니다.

## 확정 설정과 임시 규칙의 구분

확정: 45종 속성 조합·코스트 분포, 각 캐릭터 종족/직업/특성 1개, 종족/직업/특성의 전체 종류 및 단계, 최대 배치 10명, 일반 공격 AD 물리, GD의 양쪽 피해 감소, 전투 시작 유대 고정·최고 단계 하나·다른 유대 동시 판정.

이름·스킬·능력치 10종은 기획안의 제안을 그대로 구현했습니다. 계산을 위해 필요한 미정 항목은 `prototypeConfig`에 별도 저장합니다. 화면에도 ‘테스트용 임시 규칙’으로 표시합니다.

### 임시 전투 공식 / 진행

- GD: `원시 피해 × 100 / (100 + max(0, GD))`. 물리·마법 동일. 치명타·실험용 스킬 배율 계산 후 GD, 이후 보호막, 마지막 HP 순으로 적용.
- MP: 일반 공격 시 12, 피격 시 6. 마법사/사제/주술사/소환사는 각 획득량 1.5배. 기본 시작 MP 0, 시전 시 MP 0 초기화. 최대 MP 초과 없음. 보호막으로 흡수해도 피격 MP 획득. 피해 대상이 살아 있을 때 회피하지 않은 피해 이벤트마다 피격 MP 획득(DOT·스킬 다단 포함).
- 기본 공격은 직업과 관계없이 AD 물리. 기본 공격만 일반 치명타와 회피 적용. C04 스킬만 예외로 CTC +20%p / CTH와 추가 마법 피해. 소환 정령은 기획안의 예외에 따라 AP 계수 마법 공격.
- 시전 후 0.25초 행동 대기. C09 돌진은 BFS 경로의 마지막 인접 빈 칸으로 즉시 옮겨 피해·기절을 주고, 경로 한 칸마다 0.12초 추가 대기. 완전히 막히면 제자리에서 스킬 실패·MP 소모. 인접 시 이동 없음.
- 8×8, 위쪽 적 / 아래 4줄 아군 배치. 4방향 맨해튼 거리·BFS. 가까운 적 → 낮은 HP → uid 순 목표 선택. 이동 한 칸 0.35초. 이동속도 능력치 없음.
- tick 0.1초. 지속 효과 → uid 순서 개별 행동 → 승패 검사. 동시 행동이 아닌 순차 처리입니다. 같은 시전자·같은 효과는 갱신, 서로 다른 시전자 DOT는 중첩. 치유 정화는 상태 배열의 첫 해로운 효과 하나를 제거합니다.
- C02 역병충: HP180, AS0.8, RNG1, 소환 시 AP40% 물리 공격, 소환 시 AP12%를 매초 3회 마법 중독, 8초, 최대2.
- C11 화염 정령: HP220, AS0.7, RNG3, 소환 시 AP60% 마법 공격, 사망/8초 종료 시 소환 시 AP100% 마법 폭발(맨해튼2칸), 최대1. 소환수 HP는 소유자 성급별 2배. 소환 공간은 시전자에서 맨해튼3칸 내 가까운 빈 칸. 공간·상한 부족 시 MP는 소모되며 로그에 사유를 표시합니다.
- C07 튕김은 대상에서 맨해튼2칸 내 다른 적1명. C10 보호막 계수는 GD +30% 적용 후 자신의 현재 GD를 사용하고 자신은 대상에서 제외합니다.
- 모든 보호막은 개별 지속시간과 잔량으로 관리. C12의 부식은 해당 보호막이 남아 있는 동안 들어온 기본 공격에만 반응합니다. 화상4초/중독3초는 1초 간격으로 각각4/3회 피해를 줍니다.
- HP/AD/AP는 2성2배, 3성4배. 같은 ID·같은 별3명 자동 합성, 최대3성. 동일 ID 유대 중복 카운트 방지는 프로토타입 가정입니다.
- 상점5칸, 모두 같은 확률, 리롤2G. 시작12G, 승리7G/패배5G, 전투 전10G당 이자1G·최대5G. 판매는 1성1G/2성3G/3성9G. 무료 영입은 테스트 전용입니다.
- 10웨이브, 체력100, 패배 손실 `10+웨이브×2`. 90초 시간초과·동시 전멸은 패배. 체력이 남으면 다음 웨이브, 10웨이브 종료 시 체력이 남으면 원정 완주(모든 전투 승리 의미는 아님). 적 인원과 능력치 배율도 config의 임시 수치입니다.

### 유대 실험 효과와 미구현

유대 효과 콘셉트의 정확한 수치가 미정이므로 **기본값에서는 유대가 수치에 영향을 주지 않습니다.** 전체 단계 판정과 UI, 적용 대상 인터페이스는 동작합니다.

실험 모드에서는 `prototypeConfig.experimentalSynergyEffects.rules`의 **임시 단순 수치 효과**를 달성 단계 번호(1/2/3)에 비례해 적용합니다. 대상 범위 `team/members/enemy/summons`를 구분합니다. 예: 인간은 아군 전체 AD/GD, 엘프는 소속 AS/DOD, 언데드는 적 GD·치유감소, 소환사는 해당 팀 소환수 강화. 실제 적용 수치는 화면의 ‘임시 규칙’에 JSON으로 표시합니다. 이는 기획안 유대 콘셉트의 최종 효과가 아닙니다.

미구현/추후 확정: 처치 관여 중첩, 인접 유대 보호, 부활·사망 방지, 은신, 추가 화살, 연쇄 번개, 화상 전염·폭발, 동결, 정기 정화, 추가 정령병 등 유대별 복합 효과. 개별 캐릭터의 12개 제안 스킬은 별도로 구현되어 해당 상태·치유·보호막·소환을 실행합니다. 특히 기사5·암흑5의 정확한 효과는 TODO로 남깁니다. 상위 코스트 이름/스킬/수치는 만들지 않았습니다.

사제·무도가·정령 등의 미등장 직업/종족도 레지스트리와 단계는 유지합니다. 서버 계정 저장·네트워크 멀티플레이는 없습니다. 아이콘은 간단한 식별용 도형이며 미술 최종본이 아닙니다.
