# AUTOCHESS 변경 이력과 소스·문서 차이

기준 버전: **0.15.18** (package.json / dist/patch-notes.js / 화면 표기 대조). 조사 기준 소스는 v0.15.12 커밋 4fc1087634a3743c0459438d9ebd20bb372b3b3c에서 이어진 현재 작업 트리입니다. 작성 기준일: 2026-11-15 (Asia/Seoul). 이번 0.15.18은 상점·보관함·도감의 UI/이미지 표시만 변경했습니다. 보드 이미지와 좌표는 유지합니다. 게임 규칙·밸런스는 유지합니다.

**구분:** [확정 기획] 원문에 명시되거나 이후 사용자 요청으로 승인한 구조/정책. [구현] 현재 실행 경로 존재. [임시] 실행되지만 최종 밸런스 미확정. [미구현] 데이터/계획만 존재. [확인 필요] 승인·의도 또는 현재 검증으로 확정할 수 없는 부분. 구현되었다고 모든 숫자가 최종 확정인 것은 아닙니다.

## 3. 버전별 원래 변경 기록

### v0.1 — 싱글 PvE 오토체스 원형

- 동료 영입, 대기석과 전장 배치, 자동 전투를 갖춘 웹 프로토타입 추가.
- 골드, 상점 새로고침, 동일 캐릭터 합성, 조합과 진행 자동 저장을 연결.

참고: 초기 기록은 보관된 v0.1 소스와 대화의 작업 내역을 기준으로 복원했습니다.

### v0.2 — 카드 일러스트와 결과창

- 동료 표시를 일러스트 카드로 변경하고 코스트별 테두리 색을 적용.
- 보유 골드 이자 상한을5G로 확대.
- 전투 종료 결과 팝업에 획득 골드 등 보상 표시.
- 전체 화면을 검정 계열로 조정.

참고: 코스트별 테두리는 v0.9에서 코스트 원형 배지/진영 테두리로 대체되었습니다.

### v0.3 — 캐릭터 일러스트 개선

- 서브컬처풍 캐릭터 표현을 참고해 일러스트 교체.
- 캐릭터별 포즈·복장·속성 표현을 구분하고 전장 이미지 비율을 조정.

참고: 여러 차례의 일러스트 교체 작업을 묶어 기록했습니다. 원본 일러스트는 이후 보관했습니다.

### v0.4 — 식별성과 화면 공간 개선

- 작은 전장 칸에서도 알아보기 쉽게 얼굴 중심으로 확대.
- 조합의 힘을 조합으로 변경하고 현재 전장에 해당하는 조합만 표시.
- 상단 UI 높이를 줄여 전장 공간 확보.

### v0.5 — 기획안 기반 1코스트 구현

- 일러스트를 단순한 SVG 캐릭터 표현으로 변경하고 기존 일러스트 보관.
- 45명 로스터의 클래스/속성과28개 조합의 전체 단계 데이터 등록.
- C01~C12 12명의 능력치와 개별 스킬 구현.
- 능력치·마나·상태이상·소환수·치유·보호막·전투 디버그 연결.
- 고코스트 캐릭터는 초안으로만 유지하고1코스트 플레이 풀 구성.

### v0.6 — 스테이지·레벨·보급·증강

- R-S 진행과 보급/일반/보스 노드,7구간 이후 무한 진행 연결.
- 인게임 레벨3~10, XP 및4G→4XP 구매와 배치 한도 구현.
- 보급 아이템, 보스 추가 보상,2·4·6구간 증강, 임시 장비와 저장 이관 추가.
- 조합 영역 확대 및 조합 추천과 상점 강조 구현.

참고: 당시 일반/보스 기본 골드와 장비/보급 규칙은 이후 버전에서 변경되었습니다.

### v0.6.1 — 고코스트 초안 등록

- AUTOCHESS_02 기획안의 C13~C45 33명 이름·클래스·능력치·스킬 설명 등록.
- 이 단계에서는 실행되지 않는 데이터 초안으로 유지.

참고: 이후 v0.9에서2코스트11명만 실제 영입/전투를 해금했습니다.

### v0.7 — 시작 화면·난이도·적군·연승

- 게임시작과 난이도1~10 선택, 이어하기 추가. 능력치/뽑기 메뉴는 비활성.
- 메타 레벨을 인게임 레벨과 별도 데이터로 분리하되 성장 보상은 미구현.
- 난이도1 적 피해−40%부터10의+50%, 짝수 난이도마다 시작HP10 감소.
- 별도 몬스터8종과 보물 슬라임 구현. 전투당10%로1마리 교체, 처치 시40% 아이템/60% 3~5G.
- 캐릭터 능력치 작은 팝업과 필드 바깥 클릭 시 선택 해제. 타이틀 AUTOCHESS.
- 일반 기본 보상3/1G, 보스5/3G, 첫 승리부터 연승+1G·최대5G, 패배 시 초기화.

### v0.8 — 드래그·딜량·영입·장비 UI

- 전투 결과 스킬 로그를 아군 딜량 그래프로 교체하고 조합 아래 실시간 그래프 추가.
- 캐릭터 클릭은 정보 확인, 드래그는 이동/교체로 분리. 동일 캐릭터는 전장에1명 제한.
- 경험치 바와5칸 가로 진행 바 구현.
- 동료영입 버튼을 배속과 전투시작 사이에 배치하고 적 진영 위쪽 팝업으로 이동.
- 기존 상점 위치를 아이템 격자로 변경하고 아이템 드래그 장착·이전·회수 추가.
- 캐릭터당 장비3칸, 추천 최대3개, 해당 조합 강조.
- 보유3성 캐릭터는 상점에서 제외하고 판매하면 다시 등장 가능.

### v0.9 — 코스트 원형 배지·적 성급·2코스트

- 코스트 테두리 방식을 취소하고 회색/초록/파랑/보라/노랑 원형 배지 적용.
- 아군 파랑·적군 빨강 테두리.
- 상위구간이 오를 때 총2회분씩 적 성급 승급, 최대3성. 기존 적 수/배율 유지.
- C13~C23 2코스트11명의 영입·개별 스킬 해금.
- 화폐전쟁 기본 확률표를 참고해 미해금 코스트를 제외하여 환산한 레벨별 영입 확률 적용. 2코스트는Lv4부터 상점 등장.
- 영입창에 현재 확률 및 원본 표/출처 표시.

- 0단계: 기준선 기록 (`archive/BASELINE.md`).

- 2단계: Vite 빌드 도입. 게임 스크립트는 `src/legacy/`, 스타일은 `src/styles/`, 에셋은 `public/assets/`(영문 파일명). 위 문서의 `dist/…` 소스 표기는 이제 `src/legacy/…`를 가리킨다. 테스트는 Vitest로 옮겨 `tests/<기능>/`로 재구성(예전 스위트는 `archive/legacy-tests/`).
