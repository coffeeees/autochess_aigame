## A. 수정사항 6건

### A1. 동료 영입 성공 텍스트 제거

- 동료 영입창에서 캐릭터를 영입한 뒤 표시되는 **'영입완료' 텍스트 문구**를 제거한다.
- 단, 실제 영입/골드 차감/상점 매진칸/자동 합성/보유 표시/별 예고/추천 강조 및 영입창 유지 동작은 그대로 둔다.
- v0.15.17의 공통 알림 정책(T01~T41)과 별도로, 실제로 화면에 표시되는 성공 문구의 렌더링 경로를 찾아 제거한다. 실패 안내나 필요한 조작 피드백은 임의 삭제하지 않는다.
- QA: 일반 구매, 연속 구매, 합성 유발 구매, 무료 테스트 영입 경로를 구분하여 문구가 중복 표시되지 않는지 확인한다.

### A2. 전투 딜량 패널 가로 폭 확대

- **딜량 패널의 좌우 경계를 아이템 패널 폭에 맞출 필요가 없다.** 딜량 그래프/캐릭터 이름/피해 수치가 충분히 보이도록 가로 폭을 확장한다.
- 우측 화면 여유 공간을 활용하되 전장, 주요 버튼, 아이템 슬롯, 드래그/툴팁을 가리지 않도록 반응형 배치를 적용한다.
- 딜량 그래프는 기존과 같이 전투 중 표시하며, 패널 높이 및 내부 레이아웃은 내용 가독성을 우선한다.
- 아이템 패널 자체의 v0.15.17 구성(특수 2칸, 기본 12칸, 세로 스크롤, 폭 축소)은 변경하지 않는다.
- QA: 1920×1080, 1600×900, 1366×768 및 낮은 높이에서 잘림·겹침·가로 스크롤 여부 확인.

### A3. 전투 종료 하트 게이지 퇴장 모션 단축

- 현재 실제 정산 HP를 보여주는 **3.45초 충격형 하트 연출** 중, **마지막에 하트 게이지가 사라지는 퇴장 구간만** 눈에 띄게 짧게 수정한다.
- 진입, 충격, 체력 증감량, 수위/숫자 보간, 승리 민트·패배 빨강은 유지한다.
- 초기 권장값: 퇴장 모션 **150~250ms**. 실제 코드의 타임라인을 확인하여 전체 대기 시간도 불필요하게 길지 않게 조정한다. 구체값은 조정 후 보고한다.
- 전투 정산/보상/저장은 시각효과와 분리하고, 모션 감소 및 연출 중단 시에도 정상 동작해야 한다.
- QA: 승리 HP 증가, HP 100 승리(변화 0), 패배 HP 감소, 모션 감소, 화면 전환에서 확인.

### A4. C07 유하 스킬 변경

**대상:** C07 유하 / 1코스트 / 인간·궁수·번개 / 기존 스킬명 **연속 사격**.

**현행 기획서의 기존 설명:** `AD 75% 물리 피해 3회. 마지막 화살은 주변 적 1명에게 튕겨 AD 50% 마법 피해.` 튕김 반경 맨해튼 거리 2는 임시값.

**이번 확정 변경:**

- 기존 주 대상에 대한 **AD 75% 물리 피해 3회**는 유지한다.
- **마지막 공격의 연쇄 타격은 주 대상 주변의 가장 가까운 다른 적 최대 2명에게 튕긴다.**
- 연쇄 대상 각각에 **유하 AD의 70% 마법 피해**를 1회씩 적용한다.
- 주 대상은 연쇄 대상에서 제외하고, 동일 연쇄 시전에서 같은 적을 중복 선택하지 않는다.
- 유효한 추가 적이 1명뿐이면 1명, 없으면 0명만 연쇄한다. 이미 사망했거나 유효하지 않은 대상은 공격하지 않는다.
- 거리 정렬과 동률 우선순위는 현재 엔진의 기존 거리·대상 선택 관례에 맞춰 **결정론적**으로 처리하고, 실제 사용한 규칙을 보고한다.
- 기존 임시 '맨해튼 반경 2' 제한을 무조건 유지하여 가장 가까운 두 적을 배제하지 않는다. **별도 최대 튕김 반경은 이번 요청에서 확정되지 않았으므로**, 실제 스킬 사거리/전투 설계를 확인하고 필요하면 사용자에게 확인을 요청한다. 범위를 임의로 무한 확장했다고 단정하지 않는다.
- AD 계수, 마법 피해 판정, 방어/회피/보호막, 유대·장비·증강 상호작용은 현행 엔진의 정상 계산 경로를 사용한다.
- 스킬 설명, 도감, 툴팁 및 관련 데이터도 동일하게 갱신한다. 캐릭터 이름, ID, 기본 능력치, 마나 및 일반 공격은 변경하지 않는다.

### A5. 전투 시작 직후 약 1초 정지 후 장면 점프 문제 해결

**사용자 관찰:** 전투 시작 버튼을 누른 직후 화면이 약 1초 멈춰 있고, 그다음 캐릭터들이 이미 싸우고 있는 장면으로 갑자기 넘어간다. v0.15.17의 시작 성능 계측/defer 변경 후에도 증상 지속.

- 단순히 '첫 화면 로딩이 1초 느리다'는 문제로 취급하지 말 것. **전투 시뮬레이션 시간과 첫 화면 렌더링/애니메이션 시작이 어긋나는지** 우선 조사한다.
- 전투 시작 클릭 → Worker 생성/준비 → 시뮬레이션 첫 틱 → 첫 스냅샷 전달 → 첫 캐릭터 렌더 → 첫 애니메이션 프레임의 시각을 각각 측정한다.
- Worker의 경과 시간 기반 catch-up 처리, 최초 스냅샷 동기화, UI 전환·오버레이·CSS 애니메이션, 메인 스레드 초기 작업, Canvas/VFX 초기화, 렌더 루프 시작 시점 등을 점검한다.
- **기대 동작:** 전투 시작 즉시 전투 초기 상태가 보이고, 첫 이동/공격부터 시간 흐름에 맞춰 자연스럽게 재생되어야 한다. 이미 진행된 전투로 화면이 순간이동하면 안 된다.
- 원인에 맞는 최소 변경으로 수정한다. 임의의 1초 타이머/강제 대기/가짜 애니메이션으로 가리지 않는다. 시뮬레이션 승패·공격 순서·틱·배속·백그라운드 처리·저장/정산을 훼손하지 않는다.
- 일반 속도 1배, 2배, 4배, 새 원정 첫 전투, 다음 전투, 탭 전환/복귀, Worker 실패 폴백을 검증한다.
- 수정 전/후 계측값과 재현 조건을 보고한다. 로컬에서 재현되지 않으면 **미해결/재현 실패**로 명시하고 사용자 환경에서 확인할 추가 로그·측정 방법을 제시한다.

### A6. 4·5코스트 캐릭터 전체 해금

- 현재 잠겨 있는 **4코스트 8명(C34~C41), 5코스트 4명(C42~C45)** 총 12명을 모두 플레이 가능하게 해금한다.
- 상점 영입, 도감, 전장 배치, 합성, 판매, 캐릭터별 실제 스킬/전투 판정, 기존 유대 2개 적용을 연결한다.
- 전체 45명 캐릭터의 코스트별 인원은 **1코스트 12 / 2코스트 11 / 3코스트 10 / 4코스트 8 / 5코스트 4**로 유지한다.
- 기존 '해금된 1~3코스트만 재정규화한 상점 확률'은 해금 후 4~5코스트가 실제 등장하도록 수정해야 한다. **현재 기획서/코드에 있는 원본 코스트 가중치 및 레벨별 출현 확률의 근거를 확인**하고, 미해금 코스트 제거용 재정규화를 해제하여 실제 확률을 표시한다. 원본 확률표를 확인하지 못하면 임의 수치를 확정하지 말고 보고한다.
- 4·5코스트의 기존 초안 능력치/스킬을 최대한 유지하되, 실행되지 않았던 12명의 스킬은 전투 엔진에 정상 구현해야 한다. 정의가 불명확하거나 충돌하는 판정은 임의 확정하지 말고 별도 확인 항목으로 보고한다.
- 새 테마 유대 16종의 **기존 캐릭터별 2개 배정은 유지**한다. 6단계 유대 8종이 해금 후 실제 조합으로 활성화 가능한지, 각 유대별 유효 구성과 단계 계산을 검사한다.
- 기존 저장 데이터의 캐릭터, 장비, 유대 추천, 진행 상태를 보존한다. 새 해금으로 기존 1~3코스트 영입·합성 확률이 바뀌는 것은 의도된 변화지만, 그 외 경제/성급/판매 규칙은 유지한다.
- QA: 레벨별 4·5코스트 등장, 12명 전원 영입/배치/스킬/유대/합성/판매, 신규·기존 저장, 최대 3성, 6단계 유대 실제 발동 확인.

## B. 추가사항 1건 — 유하 전용 노란 연쇄 번개 VFX

- **첨부 ZIP 내부의 MD 지시서와 HTML 시각 레퍼런스를 반드시 직접 열어 확인**하고, C07 유하의 **'연속 사격' 스킬 사용 시** 실제 전투 이벤트에 연결한다.
- 해당 ZIP은 **게임에 자동으로 적용되는 플러그인이나 실행 코드가 아닌, 구현용 참고 자료**다. 실제 게임에 맞춰 Canvas/JS로 구현한다.
- 연출: 발사점의 노란 전기 스파크 → 회색/밝은 회색 짧은 막대형 비행체 → 최초 명중의 노란 섬광/각진 도트 → 실제로 선정된 최대 2명의 연쇄 대상에게 계단식 노란 번개 → 각 대상의 노란 명중 스파클 → 개별 도트 수명 종료로 소멸.
- **발사 탄환이 회색이라고 해서 모든 일반 공격에 노란 전기 효과를 추가하면 안 된다.** 유하 스킬 전용 이벤트에서만 전기 스파크·연쇄 번개를 표시한다. 기존 일반 원거리 공격의 회색 VFX 및 녹스 C01 스킬의 노란 직접 명중 효과는 유지한다.
- 연쇄 타깃/실제 피해는 **A4에서 변경한 유하 스킬 판정**이 결정한다. VFX가 자체적으로 대상이나 피해를 만들거나, 동일 대상에 중복 명중을 발생시키지 않는다.
- 실제 스킬의 발사·명중 구조와 참고 HTML의 데모 타이밍이 다르면 **엔진의 실제 이벤트를 우선**한다. VFX 때문에 스킬 피해가 지연되거나 2회 적용되어서는 안 된다.
- 선명한 정사각 도트, 별도 부드러운 광원, 부드러운 이동, 픽셀 본체의 alpha fade 금지, 개별 수명 종료 제거를 준수한다.
- 사망/회피/유효 적 부족/리사이즈/일시정지/배속/모션 감소/탭 숨김/전투 종료에 따른 정리를 확인한다.
- 첨부 MD의 '스킬 계수/대상 수 변경 금지'는 **VFX만 수정하는 일반 원칙**이며, 이번 사용자 지시 **A4(최대 2명, AD 70%)를 막는 조건이 아님**을 명확히 한다.
