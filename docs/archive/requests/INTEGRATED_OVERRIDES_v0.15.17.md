# 구현 세부 결정

아이템 패널은 0.15.15 세로 구성 복원 + 양옆 여백 축소가 우선합니다.

- 작은 화면에서 아이템 제목 줄바꿈과 휴지통 이탈을 수정했습니다. 전투 중에는 예약 2칸·스크롤 목록·삭제/복원을 유지하면서 패널을 줄이고 딜량 그래프 공간을 확보합니다. 도감·캐릭터 상세·대기석 정보에도 새 유대 2개와 전장 기준 단계를 표시하고, 유대 팝업 제목을 명시해 캐릭터 월하와 구분합니다. 좁아진 딜량 패널 제목은 세로 정렬로 줄바꿈을 정리했습니다. 차기 번호는 0.15.17로 정했습니다. Sites 스킬 절차로 기존 소유자 전용 비공개 사이트를 갱신합니다.
- 유대 효과는 기존 실험 스위치와 분리하여 항상 적용합니다. 옛 실험 스위치는 숨기고 구 28종 수치 규칙을 폐기합니다. 종족/직업/속성 메타데이터와 직업별 마나 규칙은 보존합니다.
- 공명은 시전 프레임당 원래 명중 대상별 1회, 6단계의 인접 추가 대상은 가장 작은 UID 1명입니다. 추가 피해는 자기 자신·아이템 고유효과를 재귀 발동하지 않습니다.
- 성약은 방어 계산 후·보호막 전 피해의 15%를 인접 생존 성약 멤버 중 최소 UID에게 한 번 전달합니다. 전달은 다시 방어·회피·치명타·피격 마나·반격을 발생시키지 않으며 생존 가드는 유지합니다.
- 천명 시작 인접 GD +10은 제공자 수로 중복되지 않습니다. 생명 주기 보호막은 5초이며 생명 제공량 보너스를 적용합니다. 왕권은 기절/띄우기/속박에 발동합니다.
- 윤회는 I28→P04 생존 방지 뒤 실제 사망 시 HP30% 즉시 1회 부활합니다. 부활에 처치 보상/아이템 처치 중첩/사망 시각 효과가 발생하지 않습니다. 아군 사망 중첩은 부활을 포함한 실제 치명상 때 생존 동료에게 적용합니다.
- 운명은 진영당 시작 1회만 추첨합니다. 혈광 흡혈은 장착자에게 귀속되는 전달/고유효과 피해도 실제 HP 손실만큼 한 번씩 계산합니다. 금단의 직접 스킬 분담 피해도 흡혈 합계에 포함합니다. I27 무료 추가 시전은 장비 파생으로 새 유대의 HP 비용/다음 강화/마나 환급을 다시 발동하지 않습니다. 금단은 소환수/DOT/장비 추가 피해를 제외한 직접 스킬에 적용하며 이전 시전의 강화만 소비합니다. 다음 강화는 미중첩입니다.
- 현재 엔진에는 별도 AS 수치 상한이 없습니다. 기존 쿨다운·고정 tick 행동 한계를 유지하며 임의 상한을 추가하지 않았습니다.
- 공격 순서·RNG·사거리·경로 탐색은 유지합니다. 기존 C01 스킬은 즉시 명중이므로 노란 가상 투사체를 추가하지 않습니다.
- 시작 약 1초 지연의 원인은 로컬에서 아직 재현되지 않았으며, 개선됐다고 단정하지 않습니다. 측정 조건·수치는 별도 보고서에 기록합니다.
