# AUTOCHESS — 아이템 콘텐츠 및 보상 규칙 구현 명세 (Codex용)

## 0. 작업 범위와 우선순위

이 문서는 **아이템 40종의 데이터와 보급/보스 아이템 지급 규칙만** 구현하기 위한 명세다.

- **기존 아이템 장착·해제·인벤토리·UI·저장 기능을 재구현하거나 임의로 변경하지 않는다.** 기존 데이터 모델과 API에 맞게 아래 아이템을 등록한다.
- 캐릭터당 아이템 최대 3개 장착 제한은 이미 구현되어 있으므로 유지한다.
- 기존 골드 지급 로직(승패 보상, 이자, 보너스 포함)을 **절대 변경하지 않는다.** 사용자가 골드 수치를 직접 수정했으므로 과거 문서의 숫자로 덮어쓰지 않는다.
- 현재 실제 게임에 구현된 캐릭터/상점 범위를 유지한다. 아이템 추가를 이유로 미구현 캐릭터를 활성화하지 않는다.
- 구현 전 저장소를 조사해 기존 타입, 아이템 ID, 효과 훅, 보급 및 보스 이벤트를 확인한다. 충돌 시 기존 데이터의 ID를 안전하게 매핑하고 마이그레이션한다.
- 이 문서에서 별도 표시한 **구현 가정/미확정 사항**은 기존 시스템을 우선하며, 없는 경우 임의로 파괴적인 변경을 하지 말고 보고한다.

## 1. 용어 및 진행 구조

- **메인레벨**: 게임 종료 후에도 유지되는 영구 성장 레벨. 이번 작업에서 수정하지 않는다.
- **인게임레벨**: 한 판 안에서만 적용되는 레벨. 게임 종료 시 초기화된다. 이번 작업에서 수정하지 않는다.
- **라운드**: 상위 진행 단위. 정규 구간은 1~6라운드이며 7라운드부터 무한 라운드.
- **스테이지**: 각 라운드에 5개 존재. 표기 `R-S`는 `R라운드 S스테이지`를 의미한다.
- 1라운드: 1스테이지 보급, 2스테이지 보급, 3·4스테이지 일반 전투, 5스테이지 보스.
- 2라운드 이후: 1·2스테이지 일반 전투, 3스테이지 보급, 4스테이지 일반 전투, 5스테이지 보스.
- 6-5 보스 승리 후 정규 클리어 선택 화면을 제공하며, 선택 시 7라운드부터 무한 진행한다. 해당 화면 및 메인레벨 보상은 이번 작업 범위 밖이다.

## 2. 아이템 티어 및 장착

- 아이템은 **완성형**이며 조합식/재료 합성 시스템을 새로 만들지 않는다.
- 1티어 10종(I01~I10), 2티어 15종(I11~I25), 3티어 15종(I26~I40), 총 40종.
- 1티어는 단일 기본 능력치, 2티어는 복합 능력치, 3티어는 기본 능력치와 고유 효과를 갖는다.
- 표기: `AD` 물리 공격력, `AP` 마법 공격력, `HP` 최대 체력, `GD` 방어력(물리·마법 공통), `AS` 초당 공격 횟수, `CTC` 치명타 확률, `CTH` 치명타 피해 배율, `MP` 최대 마나, `DOD` 회피 확률, `RNG` 공격 사거리(칸).
- `+N%p`는 확률/배율에 **퍼센트포인트 가산**. `AS +N%`는 현재 기본 공격속도에 대한 비율 증가. 기존 게임의 능력치 연산 우선순위가 있으면 그것을 따른다.
- 아이템은 기존 장착/해제 및 인벤토리 흐름을 사용한다.

### 3티어 효과 구현 안전 규칙

1. 동일 아이템을 여러 개 장착한 경우 **기본 능력치는 모두 적용**, **동일 고유 효과는 캐릭터당 1회만 활성화**한다. (중복 장착 자체를 금지하지 않는다.)
2. 아이템 고유 효과로 발생한 추가 공격/추가 스킬/추가 피해는 다른 아이템의 고유 효과를 연쇄 발동시키지 않는다. 무한 루프 방지를 위해 이벤트에 `source=ITEM_PROC` 등의 출처 태그를 부여한다. 단, 원래 스킬/기본 공격의 정상 효과는 유지한다.
3. 전투 중 획득한 일시적 버프, 중첩, 쿨다운, 발동 횟수는 전투 종료 시 초기화한다. 영구 스탯으로 저장하지 않는다.
4. 확률 발동은 실제 전투 적중/스킬 이벤트에 연결하고, 재현 가능한 테스트에서는 RNG를 주입할 수 있도록 한다.
5. 소환수 전용 효과는 **장착자가 생성한 소환수**에만 적용한다. 소환수의 기본 능력/지속시간 모델을 훼손하지 않는다.
6. 효과 발동은 죽은 유닛, 전투 종료 후, 무효 타깃에 발생하지 않도록 한다.
7. RNG 증가 아이템(I10, I15)은 근접 유닛의 사거리도 증가시킬 수 있다. 기존 사거리·이동·타깃 선택 엔진과 일치하게 적용한다.
8. I33의 3회 적용 중첩은 대상별로 관리하고, 3회 도달 시 기절 처리 후 카운트를 초기화하는 것으로 구현한다. 이는 **세부 구현 가정**이므로 기존 디버프 스택 정책이 있다면 그것을 우선하고 차이를 보고한다.
9. I32 화상 재적중은 중첩 피해 대신 지속시간 갱신으로 처리한다는 **세부 구현 가정**이다. 기존 화상 정책이 있다면 기존 규칙을 우선한다.
10. I27의 소환·치유·광역 스킬 재발동은 스킬별 안전한 타깃 선택과 발동 로직을 재사용한다. 재발동을 지원하지 않는 스킬은 조용히 오작동시키지 말고 구현 제약을 보고한다.
11. I34의 체력 25% 판정은 기본 공격 피해 적용 **직전** 대상 HP 비율 기준으로 한다는 **세부 구현 가정**이다.
12. I35 보호막은 유효 치유량(오버힐 제외)을 기준으로 한다는 **세부 구현 가정**이다.
13. I39의 주변 1칸은 전투 보드의 기존 인접/거리 판정 규칙을 사용한다. 스킬 피해가 여러 대상을 때릴 경우 각 피격 이벤트의 추가 피해가 과도하게 중첩될 수 있으므로, 기존 전투 이벤트 구조에 맞춰 중복 방지 및 테스트를 추가한다.

## 6. 보급 스테이지 지급 규칙 — 확정

### 6.1 스테이지 일정

- 1라운드: **1-1, 1-2** 보급.
- 2라운드 이후: 매 라운드 **3스테이지** 보급 (2-3, 3-3, …).
- 보급 스테이지는 비전투이며 기존 보급 진입/종료 흐름을 유지한다.

### 6.2 보급 UI 및 선택

- 보급마다 **무작위 완성형 아이템 4개**를 한 번에 제시한다.
- 플레이어는 **서로 다른 제시 슬롯 2개**를 선택하고, 선택한 아이템 **2개**를 획득한다.
- 4개 모두 각자의 티어를 아래 확률로 **독립 추첨**한다. 이후 해당 티어의 아이템 풀에서 무작위로 선택한다.
- 동일 아이템 ID의 중복 제시 허용 여부는 기존 시스템 정책을 따른다. 명시 정책이 없으면 **한 화면 내 중복 ID 없이** 4개를 제시하는 것으로 구현한다(세부 구현 가정).
- 보급에서 받는 아이템은 기존 인벤토리 추가 API로 전달한다. 장착/해제 기능은 수정하지 않는다.

### 6.3 라운드별 제시 아이템 티어 확률

| 라운드 | 1티어 | 2티어 | 3티어 |
|---|---:|---:|---:|
| 1 | 100% | 0% | 0% |
| 2 | 70% | 30% | 0% |
| 3 | 50% | 40% | 10% |
| 4 | 30% | 50% | 20% |
| 5 | 0% | 30% | 70% |
| 6 | 0% | 0% | 100% |
| 7+ (무한) | 0% | 0% | 100% |

- 확률은 **제시되는 4개 각각**에 적용되며, 최종 선택한 2개가 반드시 서로 다른 티어일 필요는 없다.
- 정규 6라운드 보급 횟수는 7회이며, 모든 보급을 완료하면 보급만으로 총 **14개** 획득.

## 7. 보스 승리 아이템 보상 — 확정

- 각 라운드의 **5스테이지 보스 승리** 시 해당 라운드 티어의 무작위 완성형 아이템 **1개를 확정 추가 지급**한다.
- 보스 패배 시 이 추가 아이템을 지급하지 않는다.
- 지급은 기존 인벤토리 추가 API를 사용한다.
- **기존 골드 보상 시스템을 변경하지 않는다.** 승리/패배 골드, 이자, 기타 이미 구현된 골드 관련 계산을 건드리지 않는다.
- 기존 보스 아이템 랜덤 보상 로직이 남아 있다면, 새로운 **확정 아이템 1개** 규칙과 중복 지급되지 않도록 기존 보스 아이템 지급 부분만 확인/대체한다. 단, 골드 관련 기존 동작은 그대로 유지한다.

| 라운드 | 보스 승리 확정 아이템 |
|---|---|
| 1 | 1티어 1개 |
| 2~4 | 2티어 1개 |
| 5~6 | 3티어 1개 |
| 7+ (무한) | 3티어 1개 |

- 정규 1~6라운드 보스를 전부 이기면 보스 보상 아이템 6개. 정규 구간의 보급 14개와 합계 **최대 20개**(기타 별도 아이템 획득 경로 제외).

## 8. 무한 라운드 연동

- 7라운드부터 매 라운드 3스테이지 보급: **3티어 아이템 4개 중 2개 선택**.
- 7라운드부터 매 라운드 5스테이지 보스 승리: **3티어 아이템 1개 확정 추가**.
- 무한 라운드에서 획득한 아이템/진행 성과는 **메인레벨 경험치·영구 성장 보상에 영향을 주지 않는다**. 메인레벨 보상 계산 자체는 이번 작업에서 수정하지 않는다.

## 9. 수용 기준 / 테스트

1. 아이템 데이터 40개가 ID 중복 없이 정확한 티어/이름/능력치/효과로 등록되어야 한다.
2. 기존 캐릭터 장착 3칸, 장착/해제, 인벤토리, 저장/불러오기 기능이 정상 동작해야 한다.
3. 1-1과 1-2에서는 제시 아이템 4개 모두 1티어이며 각각 2개 선택/획득 가능해야 한다.
4. 2-3, 3-3, 4-3, 5-3, 6-3의 티어 풀과 확률이 명세와 일치해야 한다. 7-3 이후는 3티어만 등장한다.
5. 보급에서 2개만 획득 가능하고 3개째 선택이 불가능해야 하며, 중복 클릭/뒤로가기/재진입으로 중복 지급되지 않아야 한다.
6. 보스 승리 시 라운드별 확정 티어 아이템 정확히 1개 추가. 보스 패배 시 0개.
7. 기존 골드 보상 로직은 변경 전과 변경 후 동일해야 한다(회귀 테스트).
8. 고유 효과가 정상 발동하고, 동일 효과 비중첩, 전투 간 초기화, 재귀 발동 방지가 작동해야 한다.
9. 장착·해제에 따른 능력치 갱신이 정확하고 기존 세이브 데이터가 깨지지 않아야 한다.
10. 테스트 또는 개발용 시뮬레이션에서 보급 확률이 장기간 추첨 시 설정값에 근접해야 한다.

## 10. 구현 결과 보고 형식

Codex는 작업 후 다음을 보고한다.

- 수정한 파일과 주요 변경 사항
- 기존 아이템·보급·보스 코드와 연결한 방식
- 수행한 테스트와 통과/실패 결과
- 기존 구현과 충돌한 부분 및 해결 방법
- 미구현/불명확한 고유 효과와 위 **세부 구현 가정**의 실제 적용 여부
- **골드 보상 로직을 수정하지 않았다는 확인**
