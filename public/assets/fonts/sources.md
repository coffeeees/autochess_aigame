# 글꼴 출처 · SIL Open Font License 1.1

- Pretendard: https://github.com/orioncactus/pretendard

원본 허가문은 같은 폴더의 pretendard-ofl.txt에 보관합니다. 기본 글꼴은 Pretendard 하나로 확정했습니다(재구축 결정 D5).

배포하는 파일은 게임에서 쓰는 글자만 남긴 `pretendard-subset.woff2`입니다(가변 굵기 유지, 한글 완성형 2,350자 + 소스에 쓰인 글자).
원본 전체 글꼴은 `assets-src/fonts/pretendard-variable.woff2`에 두고, `tools/subset-font.py`로 다시 만듭니다.
