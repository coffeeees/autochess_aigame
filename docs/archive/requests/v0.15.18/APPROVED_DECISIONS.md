## Codex 추가 판단

- 전투 중 딜량 패널 최소 높이116px(작은화면100px)를 확보하도록 아이템 목록 최대높이를 남은 공간에 맞춰 제한합니다. 준비 상태에서는 기존 높이로 되돌리고 아이템 칸·폭·삭제/복원은 유지합니다.
- 차기 버전은0.15.18로 정했습니다. 새 버전도 기존 소유자 전용 비공개 사이트를 유지합니다.
- C41 전방은 시전자→주대상 벡터와 후보 방향의 내적>0인 반평면입니다. C45는 주대상 방향을 균일하게 연장·반올림한 격자 직선이며, 주대상 셀을 포함하고 시전자 셀은 제외합니다. 기본 AI/이동/사거리는 바꾸지 않습니다.
- C34 추가회복 대상은 전체 회복 후 다시 계산한 최저HP비율입니다. C40 첫3타는 기존 일반스킬 치명타 설정(기본OFF)을 따르고 마지막만CTC+30%p로판정합니다. C45 받는피해15%는 동일상태갱신/최대값우선이며 왕권10%와는 독립 곱연산입니다.
- 상점은 기존 코드의 보관 원본 가중치를 그대로 사용합니다.45명 모두있는풀에서는재정규화없이원표와일치합니다.모든종류가3성보유로소진된특정코스트의기존빈풀재정규화는유지합니다.
- 유하의 실제 판정은 즉시 처리되므로 시연용 긴 비행 대신 짧은160/√배속 ms 회색 비행과50/√배속 ms 간격 연쇄를 시각화합니다. 피해/숫자를 지연시키거나 중복 적용하지 않습니다.
- 전투 이벤트 큐는Worker/메인각1600건,새연쇄Canvas는24건,기존입자는720개상한을유지합니다.500ms넘은시각이벤트는재생하지않습니다.
- Canvas 랜덤 입자는 별도 시각 PRNG로 분리해 Worker 실패 시 메인 전투의 Math.random 순서에 영향을 주지 않게 했습니다.
- 설정에 전투 시작 진단 로그 내려받기를 추가합니다. 시간·배속·화면정보·단계만 포함하며 저장데이터/개인정보/계정정보를 포함하지 않습니다.
- 인위적인Worker응답1초지연에서v17첫응답시뮬레이션1.0초점프를실제브라우저로재현하고수정판0.0→0.1초를확인했습니다.사용자원래현상의원인이완전히같은지는추가실사용확인이필요하며콜드자원준비대기자체가0이됐다고주장하지않습니다.
