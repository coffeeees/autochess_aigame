# AUTOCHESS — v0.15.13 이후 미적용 UI 개선 요청서

기준 버전: **v0.15.13** (사용자가 전달한 패치노트 기준)
작성일: 2026-11-15

> 이 문서는 **v0.15.13에 이미 반영된 작업을 재요청하지 않습니다.** 현재 코드와 실제 화면을 먼저 확인하고, 아래 남은 작업만 진행해 주세요. 사용자 요청 외 전투·경제·아이템 효과·증강·저장·AI 규칙을 변경하지 마세요.

## 1. 최신 오토체스류 UI 조사 및 실제 개선

- 인터넷에서 **현재 서비스 중이거나 개발 중인 최신 오토배틀러/오토체스류 게임**의 UI를 조사합니다. 2025~2026년 자료를 우선하며, TFT(전략적 팀 전투), Auto Chess, Hearthstone Battlegrounds 등을 참고 후보로 삼고 각 게임의 최신성·운영 여부를 확인합니다. Dota Underlords는 최신 운영 게임으로 단정하지 말고 필요하면 과거 참고 사례로만 사용합니다.
- 조사 초점: 영입창과 카드의 정보 위계, 전장·대기석의 공간 배분, 아이템 보관함, 시너지·추천 표시, 패널 접기/펼치기, 해상도별 가독성 및 조작 편의성.
- 조사한 결과를 **보고서 작성으로 끝내지 말고 실제 AUTOCHESS UI에 한 차례 반영**해 개선합니다. 현재 v0.15.13의 구현을 기준으로 부족한 시각적 요소를 개선하고, 기존 판타지 분위기와 핵심 화면 구조를 유지합니다.
- 참고 출처, 확인 날짜, 참고한 원칙, 실제 적용 내용 및 적용 이유를 보고합니다. 타 게임의 UI나 에셋을 그대로 복제하지 않습니다.
- 아래 명시된 수치·동작 요구를 우선합니다. 게임의 주요 구조를 바꾸거나 기능을 제거하는 대규모 재설계는 임의 실행하지 말고 별도 제안으로 남깁니다.

## 2. 아이템 슬롯 크기 재수정 — 56×56px

**현재 v0.15.13 적용 상태:** 일반/빈칸/특수 예약 슬롯 **36×36px 정사각형**, 일반 보관함 2열×6행, 초과 스크롤. 휴지통/복원 버튼은 44×28px.

**이번 변경:**
- 일반 슬롯, 빈 슬롯, 특수 예약 슬롯을 **56×56px 정사각형**으로 확대합니다.
- 아이템 아이콘은 **약 40×40px**로 확대해 식별성을 높입니다.
- **아이템 패널 자체의 폭·높이·위치·배경·테두리는 유지**합니다. 2열×6행 및 초과 스크롤을 유지하고, 필요한 경우 패널 *내부* 스크롤 영역을 조정합니다.
- 휴지통/복원 버튼은 **현행 44×28px 크기와 기능을 유지**합니다. 일반 아이템 슬롯과 동일 크기로 바꾸지 않습니다.
- CSS 선언값만 변경하고 끝내지 말고 실제 브라우저에서 슬롯이 **56×56px로 렌더링되는지 실측**합니다. 상위 레이아웃이나 미디어 쿼리에 의해 다시 축소되지 않도록 확인합니다.
- 장착·이전·회수·삭제·복원 및 특수 예약 슬롯의 제한 규칙은 변경하지 않습니다.

## 3. 동료 영입창의 과도한 크기 축소

**현재 v0.15.13 적용 상태:** 이미지 중심 5카드 영입창, 최대 폭 약 1440px, 카드 높이 약 245~360px(데스크톱). 레벨별 코스트 확률, 잠금, 새로고침, 닫기 등이 이미 구현됨.

**이번 변경:**
- 현재 과도하게 커진 영입창의 **전체 가로·세로 크기를 각각 현행 대비 약 50%로 축소**하는 방향으로 조정합니다.
- 다만 5개 후보와 필수 정보/버튼이 잘리거나 지나치게 작아져 조작할 수 없으면, 실제 가능한 크기와 충돌 사유를 보고하고 읽기 쉬운 대안을 제시합니다. 임의로 중요한 정보나 기능을 삭제하지 않습니다.
- 창 크기 축소 후에도 기존 5개 카드, 구매, 확률 수치, 잠금, 새로고침, 추천, 보유 표시, 합성 예고 및 구매 후 창 유지 기능을 보존합니다.

## 4. 영입 카드 일러스트·설명 영역 다듬기

- 카드 하단의 이름/종족/직업/특성 설명 배경을 **아래쪽은 어둡고 위로 갈수록 자연스럽게 투명해지는 그라데이션**으로 변경합니다. 이미지와 설명 영역 사이에 딱딱한 직사각형 경계가 보이지 않도록 합니다.
- 캐릭터 일러스트를 **얼굴과 어깨 중심으로 확대·크롭**합니다. 몸통이나 무기 일부는 잘려도 되지만 얼굴은 잘리지 않도록 합니다. 카드 프레임과 비율은 유지합니다.
- 모든 영입 카드에 일관되게 적용하되 캐릭터별 이미지 구도 차이를 고려합니다. 원본 PNG 파일 자체를 수정하거나 재생성하지 않고 표시 방식(CSS 등)을 조정합니다.
- 기존 코스트별 배경 그라데이션, 추천 강조, 보유 중 식별, 별 예고는 **v0.15.13 구현을 그대로 유지**합니다. 새로 구현하거나 기존 색상을 임의로 덮어쓰지 않습니다.

## 5. 조합·아이템 패널 접기/펼치기 슬라이드

- 조합 패널과 아이템 패널의 접기/펼치기 버튼에 **약 250ms 세로 슬라이드 애니메이션**을 추가합니다.
- 접을 때는 아래에서 위로 부드럽게 접히고, 펼칠 때는 위에서 아래로 펼쳐지도록 합니다. 자연스러운 가감속을 사용합니다.
- 패널 위치·외형·내부 상태·추천 및 아이템 기능을 유지합니다.
- 빠른 연속 클릭, 리사이즈, 모션 감소 설정에서도 상태가 꼬이거나 콘텐츠가 사라지지 않도록 처리합니다.

## 6. 구현 후 실제 브라우저 UI 검증 — 필수

1. 가능한 경우 브라우저를 실행해 **수정 전후 스크린샷**을 비교합니다. 브라우저 검증 도구가 없으면 검증 불가라고 명시합니다.
2. CSS 작성값이 아닌 **실제 렌더링 치수**를 확인합니다. 특히 아이템 슬롯 56×56px, 영입창의 변경 전후 폭·높이, 캐릭터 얼굴/텍스트 잘림을 보고합니다.
3. 가능하면 1920×1080, 1600×900, 1366×768 해상도에서 겹침·가독성·스크롤·조작을 확인합니다.
4. 접기/펼치기 반복 클릭, 아이템 드래그/스크롤, 영입 구매/잠금/새로고침, 추천과 보유 표시가 유지되는지 확인합니다.
5. 조사 출처, 변경 파일, 실제 적용한 디자인 원칙, 검증 성공/실패/미검증 항목을 구분해 보고합니다. 검증되지 않은 UI를 확인 완료로 보고하지 않습니다.

## 7. 명시적 제외 — v0.15.13에 이미 구현됨

아래는 **다시 구현할 작업이 아닙니다.** 현재 구현을 유지하고 이번 변경 때문에 문제가 생겼는지만 회귀 확인합니다.

- 동료 영입창의 이미지 중심 5카드 재구성 및 상단 레벨·코스트 확률·잠금·새로고침·닫기
- '원본 확률표' 펼침과 '등장 확률' 문구 제거
- 카드 코스트 숫자 배지 제거, 코스트별 회색/초록/파랑/보라/노랑 배경 그라데이션
- 추천 유대 글자 노란색, 추천 카드 발광, 보유 내부선과 '보유 중' 배지, 합성 예고 별
- C01 녹스 도감 원본 이미지 및 대기석·영입용 투명 썸네일 적용, 캐릭터 ID별 이미지 등록 구조
- 도감의 1~5코스트 색상 구분선
- 기존 보유 캐릭터, 장비, 전장 7×8 격자 및 현행 보드 이미지·비율

**최종 원칙:** v0.15.13에서 이미 끝난 작업은 재작업하지 않고, 위 **1~6번의 남은 UI 개선**만 진행합니다. UI 연구 결과를 실제 화면에 반영하되 기존 게임 기능과 저장 데이터를 보존합니다.
