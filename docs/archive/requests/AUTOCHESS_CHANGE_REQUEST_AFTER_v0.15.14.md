# AUTOCHESS v0.15.14 이후 신규 수정 요청

기준: 제공된 v0.15.14 패치노트. 아래 7건만 신규 작업으로 진행. 기존 구현 사항 재작업 금지.

## 1. 백그라운드 전투 진행
- 탭 전환/창 최소화 시 게임 전투 진행이 멈추는지 재현 및 원인 조사.
- requestAnimationFrame, setTimeout, visibilitychange, 기존 일시정지 로직 확인.
- 백그라운드에서도 전투 계산/시간/승패/보상 진행. 화면 렌더링은 복귀 시 갱신 가능.
- 사용자가 직접 일시정지한 상태는 계속 정지. 복귀 시 중복 정산/타이머 폭주 금지.
- 일반/보스 전투, 1·2·4배속, 탭 전환, 최소화, 복귀를 테스트.

## 2. 아이템 패널 크기에 맞는 슬롯 조절
- 현재 56×56px 슬롯·40×40px 아이콘을 기준으로 실제 패널 너비/높이에 맞게 슬롯, 간격, 패딩 조절.
- 패널을 불필요하게 확대하지 말 것. 2열×6행, 초과 스크롤, 특수 2칸, 휴지통/복원 유지.
- 1920×1080, 1600×900, 1366×768 실제 브라우저 검증 후 최종 px 보고.

## 3. 딜 그래프 등장 시 아이템 패널 하단 잘림
- 전투 중 실시간 딜량 그래프가 나타날 때 우측 아이템 패널 아래쪽이 잘리는 문제 재현.
- flex/grid 높이, overflow, z-index, 그래프 공간 확보, 접기/펼치기 점검.
- 그래프 표시 여부, 초과 아이템, 작은 화면에서 슬롯/버튼 접근 가능하게 수정.

## 4. 3티어 동일 장비 중복 착용 허용
- 기존 T1/T2만 중복 가능하던 정책을 변경: T1/T2/T3 모두 동일 ID 장비 중복 착용 가능.
- 캐릭터당 최대 3개 제한 유지. 장착/이전/저장/로드/합성/판매/툴팁 점검.
- 동일 T3 금지 알림(T24)은 더 이상 발생하지 않게 수정.
- T3 고유 효과의 중첩·독립 발동·전투당 1회 판정은 기존 코드 분석 후 모호한 부분을 별도 보고. 임의 밸런스 변경 금지.

## 5. 이미지 등록 캐릭터 얼굴 강조
- 실제 PNG가 등록된 캐릭터의 전장/대기석/영입 이미지에서 얼굴·상반신을 지금보다 크게 표시.
- 원본 PNG 수정 금지. 얼굴이 잘리지 않도록 캐릭터별 object-position/scale 조정 가능하게 구현.
- 별, HP/MP, 이름, 속성 텍스트와 겹침 방지. 도감 원본 전체 보기 유지.

## 6. 적 진영 빨간색 테두리 강화
- 준비 단계 적 진영 위쪽 4행의 빨간 테두리 가시성 점검.
- 대비/두께/안쪽 그림자/레이어를 조절해 배경 위에서도 뚜렷하게 표시.
- 아군 파란 테두리와 구별. 논리 7×8 좌표, 보드 이미지 정합, 전투 판정 유지.

## 7. 상단 진행바 노드 라벨 삭제·원 확대
- 각 노드 아이콘 아래의 1-1, 1-2 등 단계 번호 라벨 삭제.
- 원형 노드와 보급/전투/보스 아이콘을 현재보다 크게 표시.
- 완료/현재/예정 상태, 진행 판정 유지. 반응형 화면에서 HUD 겹침 금지.
- 단계 정보가 필요한 기존 별도 스테이지 표시까지 삭제하지 말 것.

## 필수 검증·보고
- 7개 항목별 수정 파일, 변경 전/후, 실제 브라우저 테스트 결과 명시.
- 기존 전투·경제·유대·아이템·저장 기능 회귀 테스트.
- 실제 브라우저 검증이 불가능하면 명확히 알릴 것.
- 패치노트에 이번 신규 수정 7건을 기록하고 이전 패치 내용만 반복하지 말 것.
