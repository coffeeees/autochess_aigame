# AUTOCHESS UI 개선 작업 지시서

- 기준 버전: **v0.15.6**
- 문서 성격: Codex 구현 요청 및 알림 현황 조사
- 작업 범위: UI/UX 개선, 기존 기능 재사용. 게임 계산 및 저장 규칙은 임의 변경하지 않는다.
- 버전 번호는 구현 후 프로젝트의 기존 버전 관리 방식에 따라 갱신한다.

## 1. 캐릭터 드래그 시 양쪽 판매 영역 등장

### 요구사항
- 전장 또는 대기석의 **판매 가능한 아군 캐릭터를 실제로 드래그하기 시작한 동안** 화면 **하단 좌우 가장자리**에 판매 드롭 영역 두 개를 표시한다.
- **왼쪽 판매 영역:** 화면 왼쪽 바깥에서 안쪽(→)으로 슬라이드 등장.
- **오른쪽 판매 영역:** 화면 오른쪽 바깥에서 안쪽(←)으로 슬라이드 등장.
- 두 영역에는 **`판매` 문구와 드래그 중인 캐릭터의 판매 시 획득 골드(G)**만 표시한다. **캐릭터 이름은 표시하지 않는다.**
- 판매 가격은 기존 계산식 **코스트 × 3^(성급−1)**을 그대로 사용한다. 기존 판매 처리 함수와 상태 갱신을 재사용한다.
- 어느 쪽 판매 영역에 드롭하든 해당 캐릭터를 한 번만 판매한다. 드롭 가능한 영역에 커서가 진입하면 강조 표시한다.
- 판매 영역 외에 드롭하거나 드래그를 취소하면 기존 이동/교체/원위치 복귀 동작을 유지하고, 판매 영역은 좌우 바깥쪽으로 슬라이드 퇴장한다.
- 단순 클릭이나 정보 열람만으로는 판매 영역이 나타나지 않도록 한다.
- 하단 대기석, 영입 및 전투 시작 버튼의 조작을 불필요하게 가리지 않도록 판매 영역의 크기·위치·레이어를 조정한다. 작은 화면에서도 양쪽 판매 영역을 사용할 수 있도록 처리한다.
- 드래그 종료, 취소, 화면 전환 등 예외 상황에서 판매 영역이 남지 않도록 한다. 모션 감소 설정에서는 과도한 이동 애니메이션을 줄인다.

## 2. 우측 아이템 보관함 UI 확대

- 현재 우측 **아이템 보관함(Inventory) 패널 전체**와 내부 **아이템 슬롯**을 전반적으로 더 크게 만들어 시인성과 조작 편의성을 높인다.
- 특수 예약 슬롯 2칸, 기본 일반 슬롯 16칸(4열 × 4행의 현재 표시 구조), 휴지통 및 되돌리기 아이콘 버튼도 확대된 레이아웃에 맞게 조정한다.
- 아이템이 늘어날 때의 기존 보관함 확장 동작, 아이템 드래그/장착/회수, 툴팁과 버튼 기능은 유지한다.
- 패널 확대로 인해 체스판, 상단 HUD, 하단 대기석 및 다른 팝업이 가려지지 않도록 1920×1080을 우선 점검하고, 작은 화면에서의 축약·스크롤도 확인한다.
- **확대 배율이나 최종 픽셀 크기는 아직 확정하지 않았다.** Codex는 기존 대비 개선된 시안을 구현하고 변경 전후 크기를 패치노트에 기록한다. 전장 확대와 충돌하는 경우 임의로 전장을 축소하지 말고 조정 사항을 보고한다.

## 3. 대기석 위 공통 알림의 발생 조건 전수 조사 및 패치노트 별도 항목

### 목적
- 현재 대기석 위 중앙에 나타나는 일반 알림이 너무 자주 발생하는 것으로 느껴진다.
- **이번 단계에서는 알림을 임의로 제거하거나 빈도를 변경하지 않는다.** 실제 코드에서 어떤 조건에 알림이 나타나는지 먼저 확인하고, 이후 사용자가 삭제·유지 여부를 결정할 수 있도록 한다.

### Codex 조사 지시
- 현재 공통 알림(토스트/Toast)을 호출하는 코드와 발생 경로를 **전수 조사**한다. 캐릭터 영입, 판매, 합성, 중복 배치, 레벨/XP 구매, 골드 부족, 아이템 관련 조작 등은 **조사 대상 예시**이며 실제 발생 여부는 코드로 확인한다.
- 패치노트에 독립된 **`공통 알림 발생 조건 목록`** 섹션을 신설하고, 각 항목에 다음 내용을 표로 정리한다.
  1. 알림이 뜨는 실제 조건/사용자 행동
  2. 화면에 표시되는 알림 문구(동적 값은 변수 형태로 기재)
  3. 관련 기능 또는 코드 위치(가능하면)
  4. 중복·연속 발생 가능성 또는 동일 행동에서 여러 알림이 뜨는지
  5. 현재 상태: 유지 중 / 검토 필요 (삭제 여부는 사용자 미결정)
- 공통 알림과 확인 모달, 툴팁, 전투 결과창 등은 구분한다. 조사 결과 알림이 없는 항목은 있는 것처럼 작성하지 않는다.
- 현재 공통 알림의 위치(대기석 위 중앙), 기본 표시 시간(5초), 새 알림 도착 시 표시 시간 갱신 동작을 조사 결과에 함께 기록한다.
- 사용자 검토 전에는 알림 노출 조건·문구·시간·횟수를 바꾸지 않는다.

## 4. 하단 패널의 세로 구분선 추가

- 현재 하단 바는 **`레벨/XP | 대기석 10칸 | 동료 영입·전투 시작 버튼 영역`**의 세 그룹으로 인식되도록 한다.
- 다음 **두 경계**에 명확하지만 과하지 않은 **세로 구분선(Vertical Divider)**을 추가한다.
  - 레벨/XP 버튼과 대기석 사이
  - 대기석과 동료 영입·전투 시작 버튼 묶음 사이
- `/` 기호를 실제 문자로 표시하라는 뜻이 아니라 **시각적 세로 선**으로 그룹을 구분하라는 뜻이다.
- 기존 패널 스타일(어두운 판타지 톤, 은은한 테두리/광원)에 어울리게 적용하고, 구분선 때문에 슬롯 크기나 버튼 클릭 영역이 부자연스럽게 줄어들지 않게 한다.
- 대기석 10칸 및 기존 드래그·합성·영입·전투 시작 기능은 그대로 유지한다.

## 5. 변경 금지 및 검증

### 유지할 사항
- 논리 전장 **7열 × 8행**, 아군 배치 아래 4행.
- v0.15.6의 **배경 이미지와 투명 체스판 PNG의 독립 레이어 구조**.
- 캐릭터 판매 가격, 골드/XP, 전투, 아이템, 증강, 영입 확률, 저장 데이터 등 기존 게임 규칙.
- 하단 대기석 **10칸**, 기존 영입/전투 시작 동작.
- 기존 알림 조건은 사용자가 검토하기 전까지 유지.

### 검증 체크리스트
- [ ] 캐릭터를 드래그할 때만 좌우 판매 영역이 올바른 방향으로 등장한다.
- [ ] 두 판매 영역에 `판매`와 정확한 획득 골드만 표시되고 이름은 표시되지 않는다.
- [ ] 왼쪽/오른쪽 어느 곳에 드롭해도 정확히 한 번 판매된다.
- [ ] 영역 밖 드롭/드래그 취소 시 판매되지 않고 영역이 사라진다.
- [ ] 기존 캐릭터 이동/교체, 합성, 장비 반환 및 판매 후 상태 갱신이 정상 작동한다.
- [ ] 아이템 패널과 슬롯이 더 크게 표시되며 아이템 드래그/장착/회수/휴지통/복원 기능이 정상이다.
- [ ] 하단 세 그룹 사이에 구분선 두 개가 표시되고 버튼 조작을 방해하지 않는다.
- [ ] 패치노트에 **실제 코드 기준** 알림 발생 조건이 별도 표로 정리된다.
- [ ] 1920×1080 및 작은 화면에서 UI가 겹치거나 잘리지 않는다.
- [ ] 기존 전투·경제·저장 동작에 회귀 오류가 없다.

## 6. 작업 완료 시 보고 요청

1. 적용한 UI 변경 사항과 주요 변경 파일
2. 아이템 보관함 패널/슬롯의 변경 전후 크기 또는 배율
3. **패치노트에 신설한 공통 알림 발생 조건 목록 전체**
4. 테스트 결과와 남아 있는 제약 사항
5. 가능하면 **1920×1080 화면 스크린샷**

> 참고: 이번 요청의 핵심은 UI 개선과 알림 현황의 가시화다. **알림 삭제/축소 대상은 아직 확정하지 않았으므로 Codex가 임의로 판단하지 않는다.**
