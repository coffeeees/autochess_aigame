# 판타지 오토체스 — Codex 구현 인수인계 (1코스트 프로토타입)

## 최우선 지시
- PC 브라우저용 판타지 오토체스 프로토타입을 만든다.
- **실제 상점·배치·전투에 등장하는 캐릭터는 C01~C12 (1코스트)만** 사용한다.
- C13~C45는 전체 로스터 데이터에 보관하되 상점·전투·랜덤 선택에 절대 등장시키지 않는다. 이름/스킬/능력치를 만들어내지 않는다.
- **종족 9, 직업 9, 특성 10의 전체 유대 종류와 단계는 등록**하고 범용 판정 엔진을 만든다. 도달 불가능한 단계도 삭제하지 않는다.
- 확정 설정과 테스트용 수치/제안 스킬을 분리한다. 미정인 세부 공식은 설정 파일에 모아 TODO로 표시하고, 구현을 위해 필요한 임시값만 명시한다.
- 이미지 생성은 불필요하다. 기능 중심의 PC 웹 UI를 만든다.

## 1. 확정된 기본 설정
- 장르: 판타지 오토체스; 플랫폼: PC 웹 브라우저; 최대 전장 배치 10명.
- 전체 로스터 45종; 코스트 1~5, 분포 1코스트 12 / 2코스트 11 / 3코스트 10 / 4코스트 8 / 5코스트 4.
- 캐릭터마다 종족, 직업, 특성 각 1개씩 정확히 가진다.
- 유대는 전투 시작 시 배치된 서로 다른 캐릭터 종류를 기준으로 계산한다(동일 ID의 중복 배치가 가능해지더라도 중복 카운트 방지는 **프로토타입 가정**, 추후 확정 필요).
- 전투 중 사망해도 유대 단계 유지. 유대별 달성한 최고 단계 하나만 적용. 서로 다른 유대는 동시 적용 가능. 효과 적용 대상은 유대마다 다름.
- 일반 공격은 **모든 직업 AD 기반 물리 피해**. 스킬은 직업별 주력 계수를 사용하되 개별 예외 가능.
- 마법 계열(마법사/사제/주술사/소환사)은 MP가 더 빨리 충전되어 스킬을 자주 사용하는 방향.
- GD는 물리 피해와 마법 피해 모두 감소시킴. 이동속도 능력치는 없음(전장 이동 동작은 별도 공통 규칙).

## 2. 능력치 10종
| 키 | 뜻 | 단위/해석 |
|---|---|---|
| HP | 체력 | 생명력 |
| MP | 마나 | 여기서는 캐릭터의 최대 마나로 기록; 현재 마나는 전투 상태로 별도 관리 |
| AD | 물리 공격력 | 일반 공격 및 AD 스킬 계수 |
| AP | 마법 공격력 | AP 스킬 계수 |
| CTH | 치명타 피해 | 배율(%), 예: 150% = 1.5배 |
| CTC | 치명타 확률 | % |
| GD | 방어력 | 물리·마법 공통 피해 감소에 사용 |
| AS | 공격속도 | 초당 기본 공격 횟수 |
| RNG | 공격 사거리 | 전장 칸 단위 |
| DOD | 회피율 | % |

직업별 주력 계수 **제안**: 전사 AD, 기사 AD+GD, 궁수 AD, 마법사 AP, 암살자 AD+CTH, 사제 AP, 주술사 AP, 소환사 AP, 무도가 AD+AS. 특정 캐릭터 스킬이 다르면 스킬 정의를 우선한다.

### 스킬 사양 초안
- **C01 불씨 화살 (AD):** 현재 대상에게 AD 160% 물리 피해. 화상 4초, 매초 AD 15% 마법 피해.
- **C02 맹독의 하수인 (AP):** 8초 지속 역병충 소환, 최대 2마리. 역병충 공격력은 시전자 AP 40%. 공격 시 3초 중독. **중독 피해량·소환수 HP/AS/RNG 미정.**
- **C03 그림자 베기 (AD):** 현재 대상에게 AD 180% 물리 피해, 4초간 대상 AD 15% 감소.
- **C04 섬광 찌르기 (AD):** 대상 AD 200% 물리 피해, 해당 공격 CTC +20%p. 치명타면 AD 50% 추가 마법 피해.
- **C05 치유의 물결 (AP):** 현재 HP 비율이 가장 낮은 아군을 AP 180% 회복, 해로운 상태이상 1개 제거.
- **C06 바람 가르기 (AD):** 현재 대상에게 각각 AD 140% 물리 피해 2회, 이후 4초간 자신 AS +20%.
- **C07 연속 사격 (AD):** 대상에게 AD 75% 물리 피해 3회, 마지막 화살은 주변 적 1명에게 튕겨 AD 50% 추가 마법 피해. **주변 범위 미정.**
- **C08 심연의 물구슬 (AP):** 대상에게 AP 220% 마법 피해, 3초간 AS 15% 감소.
- **C09 용의 돌진 (AD):** 대상에게 돌진하여 AD 170% 물리 피해, 1초 기절. 인접 대상이면 이동 없이 공격. **돌진 경로 규칙 미정.**
- **C10 대지의 수호 (GD):** 5초간 자신의 GD +30%, 인접한 아군 중 HP 비율이 가장 낮은 1명에게 자신의 GD 200% 보호막.
- **C11 화염 정령 소환 (AP):** 8초 지속 화염 정령 소환, 최대 1마리. 정령 공격은 시전자 AP 60% 마법 피해. 사망 또는 지속시간 종료 시 주변 적에게 AP 100% 마법 피해. **소환수 HP/AS/RNG/폭발 범위 미정.**
- **C12 부식의 방패 (GD):** 5초간 자신에게 GD 250% 보호막. 보호막 유지 중 자신을 기본 공격한 적에게 3초간 GD -15% 부식.

## 6. 이번 프로토타입의 유대 테스트 가능 범위
- 1코스트만으로 **2명 단계** 가능한 종족: 인간(C03,C07), 엘프(C04,C05), 마족(C02,C06), 언데드(C01,C08).
- 1코스트만으로 **1명 단계** 가능한 종족: 용족(C09).
- 1코스트만으로 **2명 단계** 가능한 직업: 전사(C03,C09), 기사(C10,C12), 궁수(C01,C07), 암살자(C04,C06), 소환사(C02,C11).
- 1코스트만으로 **2명 단계** 가능한 특성: 화염(C01,C11), 번개(C04,C07), 물(C05,C08), 바람(C06,C09), 독(C02,C12).
- 그 외 유대도 정의 및 판정은 구현하되, 현재 캐릭터 풀에서 달성 불가능한 단계는 UI에 잠금/미달성 상태로 표시한다.
- 캐릭터가 사망해도 이미 발동된 유대가 사라지지 않는지 검사한다.

## 7. 구현 시 미확정 항목 및 임시 처리 원칙
1. GD 피해 감소 공식, 마나 획득량(일반 공격·피격·마법 계열 보너스), 시작 마나, 스킬 시전 시간, 마나 소모 후 초기화 방식 미정.
2. 치명타 적용 범위(기본 공격/스킬), 회피 적용 범위, 상태이상 중첩/갱신 규칙 미정.
3. 전장 크기, 경로 탐색, 목표 선정, 배치 좌표, 소환수 배치, 동시 행동 처리 미정.
4. 상점 확률·리롤·경제·레벨업·합성·성급 성장·승패 규칙 미정.
5. 유대 효과의 **정확한 수치**는 미정이며, 기사 5와 암흑 5의 최종 효과는 특히 재설계 필요.
6. 2~5코스트 캐릭터의 이름/스킬/능력치는 미정.
7. 구현을 위해 임시값이 필요한 경우 `prototypeConfig`에 분리하고 화면에 '테스트용 임시 규칙'이라고 명시한다. 확정 기획 문서를 덮어쓰지 않는다.

## 8. Codex 작업 요청 / 완료 기준
- 데이터 중심 구조로 구현: `synergies` 전체 28종(종족 9 + 직업 9 + 특성 10), `roster` 45종, `playableIds` C01~C12, `skills` 12종, `prototypeConfig`.
- 유대 카운트와 최고 달성 단계 판정은 순수 함수로 만들고 테스트한다.
- PC 웹에서 1코스트 캐릭터를 선택·배치하고 전투를 시작해 일반 공격, MP 증가, 스킬 사용, 피해/치유/보호막/상태이상/소환을 확인할 수 있게 한다.
- 디버그 UI: 캐릭터별 HP/현재MP/최대MP, 능력치, 적용 유대, 피해 로그, 상태이상, 전투 결과, 임시 규칙 확인.
- 유대 수치가 미정이면 임의로 정식 수치를 만들지 말고 **유대 단계 판정과 UI는 정상 동작**시키며, 실험용 효과는 별도 설정 스위치로만 활성화한다.
- 테스트: 로스터 45종 및 코스트 분포, 각 캐릭터 속성 정확히 1개씩, 1코스트 풀 제한, 유대 단계 판정, 사망 후 유대 유지, 일반 공격 AD, GD 양쪽 피해 유형 적용.
- 실행 방법, 테스트 방법, 임시로 정한 규칙 목록, 미구현 항목을 README에 남긴다.
- 기존 프로젝트가 있으면 구조를 먼저 살펴보고 그 기술 스택에 맞춰 구현한다. 프로젝트가 없다면 단순한 웹 개발 환경을 선택해 실행 가능한 프로토타입을 만든다.
